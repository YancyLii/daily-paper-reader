## 摘要
通过 Ollama 等推理引擎本地部署的大语言模型（LLM）运行时，缺少 API 服务模型中所具备的内容审核与滥用检测机制。因此，LLM 的安全性取决于所使用的防御机制，而这些防御机制的有效性又取决于其设计时所依据的假设。本文对本地部署模型在越狱攻击下的防御机制进行了审计。一些防御机制提供形式化保证（SmoothLLM、Erase-and-Check、Sequential Monitors），另一些则依赖经验性检测结果（Semantic Smoothing、Self-Denoised Smoothing、Perplexity Filtering）。我们并非仅仅观察防御失败的现象，而是将每一次失败追溯到具体假设：针对每一种防御，我们提取其依赖的条件，推导出违反该条件应产生的经验模式，并在六个开源权重模型（参数量从 14B 到 35B）上使用来自 40 多个公开来源的 100 条越狱提示语料库对该预测进行测试，共计 13,800 条评估记录。

## Abstract
Locally deployed Large Language Models (LLMs) via inference engines such as Ollama run without the moderation and abuse detection present in API-served models. Therefore, the safety of LLMs depends on the defense mechanisms used, and their effectiveness depends on the assumptions on which they were designed. This paper does an audit of defense mechanisms under jailbreak attacks on locally deployed models. Some defenses provide formal guarantees (SmoothLLM, Erase-and-Check, Sequential Monitors), while others rely on empirical detection results (Semantic Smoothing, Self-Denoised Smoothing, Perplexity Filtering). Instead of merely observing that defenses fail, we trace each failure back to the specific assumption: for every defense, we extract the condition it relies on, derive the empirical pattern a violation should produce, and test that prediction on six open-weight models (14B to 35B parameters) with a corpus of 100 jailbreak prompts taken from more than 40 public sources, totalling 13,800 evaluation records.

- 本地部署的大语言模型（如通过 Ollama 运行的开放权重模型）缺少 API 服务中内置的审核与滥用检测，因此其安全性几乎完全取决于部署时选择的输入侧防御机制。
- 现有防御机制大多针对 token 级越狱攻击（如 GCG、AutoDAN、PAIR）设计，这些攻击的特征是：对抗内容集中在紧凑的后缀中、统计上异常、对字符扰动脆弱。
- **语义越狱攻击**则完全不同：它们使用流畅的日常语言，将有害意图隐藏在角色扮演、人格注入、假设场景或多轮分解中，不存在可删除的对抗后缀，困惑度与正常文本无异。
- 因此，本文的核心问题不是“防御是否失效”，而是：**这些防御所依赖的设计假设，在语义攻击下是否仍然成立？** 如果假设被违反，失效会呈现怎样的可预测模式？
- 整体含义是：防御机制的有效性由其前提条件决定；如果前提在攻击面发生变化时被系统性打破，那么即使防御具有形式化保证或良好的基准成绩，也可能完全失效，甚至产生净有害效果。

### 2.4 相关形式化公式（文字说明）

- **SmoothLLM**：定义对抗后缀为 k-不稳定（改变至少 k 个字符后越狱失败），防御成功概率 DSP 为 N 个扰动副本中多数结果为安全的二项式概率；当语义攻击的 m_s ≈ m 且 k > M 时，单副本逃逸概率 α 趋近于零，投票退化为无防御行为。
- **Erase-and-Check**：证书声称对任何长度 ≤ d 的对抗后缀，至少一个擦除版本与干净有害提示一致，因此检测准确率不低于底层过滤器；语义攻击没有这种局部后缀时，完整性方向失效。
- **Self-Denoised Smoothing**：掩码 m=0.3 的位置，用 LLM 去噪重建后分类并多数投票；原始证书仅适用于 SST-2/Agnews 的词替换鲁棒性，不适用于越狱，因此归类为 T2。
- **Sequential Monitors / CUSUM**：论文未指定累积统计量，作者用 Page's CUSUM 实例化：每轮增量 ℓ_i 为对数似然比，G_i = max(0, G_{i−1} + ℓ_i)，当 G_i ≥ h 时停机。CUSUM 的最优性依赖良性流量负漂移、攻击流量正漂移的**漂移分离前提**。
- **Perplexity Filtering**：PPL(x) = exp(−(1/n) Σ log Pθ(x_t | x_<t))，高于阈值则标记；阈值在 GCG 字符串上接近 1000。
