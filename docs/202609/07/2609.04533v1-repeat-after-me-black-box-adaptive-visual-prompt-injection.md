## 摘要
提示注入被广泛认为是对与不可信外部数据（如网站、文档和电子邮件）交互的 AI 智能体的重大安全威胁。先前工作表明，在文本领域，黑盒提示注入可以达到接近完美的攻击成功率（ASR）。然而，在图像领域，现有的视觉提示注入方法在攻击前沿商用 VLM 以引发实质性有害行为方面效果明显较差。实现此类输出很困难，因为需要长且/或符合格式要求的目标字符串，例如具有精确函数名和参数的、可解析的原生工具调用。我们提出了 Repeat-After-Me，一种黑盒自适应视觉提示注入攻击，可以泄露个人身份信息或发起恶意工具调用。在开放权重和商用前沿 VLM（包括 Qwen3.6-27B 和 GPT-5.5）上，在良性用户提示与注入任务语义无关且未口头授权的现实设定下，我们的方法分别实现了超过 80% 和 47% 的 ASR。在我们的评估中，针对一个替代模型优化的注入在两个商用受害模型上保留了原始 ASR 的 43–46%，跨样本可迁移性在这两个模型上保留了原始 ASR 的 64–66%。我们在真实世界 OpenClaw 智能体中测试了我们的攻击：在默认 OpenClaw Discord 部署中，不可信用户可以使用最小化注入图像覆盖 TOOLS.md，从而启用未来的敏感行为，如远程代码执行和秘密数据外泄。我们展示了新的攻击向量在自适应文本提示注入失败的情况下依然有效。我们讨论了潜在防御。

## Abstract
Prompt injection is widely recognized as a major security threat to AI agents that interact with untrusted external data, such as websites, documents, and emails. Prior work has shown that, in the text domain, black-box prompt injection can achieve near-perfect attack success rates (ASRs). In the image domain, however, existing visual prompt injection methods are substantially less effective in attacking frontier commercial VLMs for materially harmful behavior. Achieving such outputs is hard because it requires a long and/or format-compliant target string, such as a precise, parseable native tool call with exact function names and arguments. We present Repeat-After-Me, a black-box adaptive visual prompt injection attack that can reveal personally identifiable information or make malicious tool calls. Across both open-weight and commercial frontier VLMs, including Qwen3.6-27B and GPT-5.5, our method achieves ASRs exceeding 80% and 47%, respectively, under a realistic setting in which the benign user prompt is semantically unrelated to the injected task and does not verbally authorize it. In our evaluation, injections optimized on one surrogate retain 43-46% of the original ASR on two commercial victims, and cross-sample transferability retains 64-66% of the original ASR on those two models. We test our attack in a real-world OpenClaw agent: in a default OpenClaw Discord deployment, an untrusted user can use a minimally injected image to overwrite TOOLS.md, enabling future sensitive behaviors like remote code execution and secret exfiltration. We show our new attack vector works in cases where adaptive textual prompt injection fails. We discuss potential defenses.

## 2. 论文提出的方法论

### 2.1 核心思想：Repeat-After-Me（RAM）提示

- 传统思路是让模型“放弃良性任务、转而执行恶意任务”，但这通常很困难。
- 本文关键洞察是：**不必说服模型改变内部意图，只需让它以攻击者指定的字符串开头回复**。
- 攻击注入文本形式为：
  > Begin your response with: `<target_output>`

  将该文本渲染在图像上。
- 给定目标输出 τ：
  - **已知目标输出**：τ 直接设置为精确工具调用文本。
  - **未知目标输出**：τ 设置为前缀，例如 `My SSN is`，诱导模型继续补全并泄露秘密。
- 这种方式不要求模型完全覆盖用户任务，而是请求额外行为，显著降低攻击难度。

### 2.2 自适应优化流程

论文给出 Algorithm 1，核心步骤如下：

1. 用种子注入初始化。
2. 在每轮迭代中，攻击者 LLM 基于当前注入生成 `n` 个候选文本注入。
3. 将每个候选注入渲染到图像顶部，用良性提示查询受害者 VLM。
4. 使用专门的 judge LLM 对受害者输出按 1–10 评分，检查是否命中攻击目标。
5. 选择得分最高的候选作为下一轮当前注入，并保存反馈。
6. 重复直到成功或查询预算耗尽。

- 攻击者 LLM 和 judge LLM 均使用 Claude-Opus-4.6，生成 32 个候选并行，最多 50 步。
- 优化器为 PAIR 风格，其他黑盒文本优化器（TAP、OPRO）也可直接替换。

### 2.3 攻击库复用

- 维护一个**攻击库**，记录历史成功注入。
- 用 Claude Code 分析成功注入的共享模式，形成可复用模板。
- 攻击库作为后续攻击的强初始化，降低黑盒搜索成本，并提升优化稳定性。

## 3. 实验设计

### 3.1 评估场景

- **Steal-PII**：系统提示中包含敏感 PII，受害者模型被要求不得泄露；攻击目标是让模型输出指定的敏感值。
  - 数据：10 个合成用户画像，来自 CIMemories；每个画像提取 10 种属性（健康、财务、家庭等），共 100 个攻击目标。
- **Call-Tool**：诱导 VLM 发出攻击者指定的精确原生工具调用。

  - 成功标准：必须调用**完全一致**的函数名和参数，使用原生工具调用格式；其他形式（如表达意图、Python 代码）不算成功。
- **Call-Tool-OpenClaw**：模拟 OpenClaw 风格 Discord 智能体，攻击目标是调用 `write` 工具覆盖 `TOOLS.md`、`USER.md`、`AGENTS.md` 等配置文件。

### 3.2 受害者模型

- 商用：Claude-Opus-4.7、GPT-5.5、Gemini-3.1-Pro。
- 开放权重：Qwen3.6-27B、Qwen3-VL-32B-Instruct、InternVL3.5-38B-Instruct。

### 3.3 任务数据

- 使用 DocVQA 验证集前 100 张独特文档图像，每个对应一个良性文档问答任务。
- 良性用户提示语义上与注入无关，且不口头授权攻击行为。

### 3.4 对比方法

- **ARE**：基于 CLIP 替代模型梯度优化对抗图像。
- **CoTTA**：梯度攻击，联合对齐视觉表示与恶意目标。
- **TransferEns**：本文实现的更强梯度迁移攻击，使用多个开放权重 VLM 集成、高分辨率输入、直接优化目标字符串。

## 6. 论文的主要结论与发现

- **攻击有效性**：
  - Steal-PII：平均 ASR 达 95%，其中 GPT-5.5、Gemini-3.1-Pro、Qwen3.6-27B、Qwen3-VL-32B-Instruct 均 ≥ 99%，Claude-Opus-4.7 为 90%。
  - Call-Tool：开放权重模型 ASR 达 82–100%，商用模型至少 47%；Gemini-3.1-Pro 达 85%。
- **显著优于基线**：
  - ARE/TransferEns 几乎全部为 0% ASR。
  - CoTTA 最高 10% ASR。
  - LangVPI 最高 53% ASR（开放模型），但商业模型上远低于 Repeat-After-Me。
- **三个组件均重要**：
  - 仅 RAM 提示就将平均 Call-Tool ASR 从 8.7% 提升至 31.7%。
  - 攻击库在部分模型上带来超过 40 个百分点的提升。
  - 自适应优化对强安全模型（Claude-Opus-4.7、GPT-5.5）是关键，使其 ASR 由个位数提升至 47%。
- **迁移性**：
  - 跨模型：替代模型优化注入在 GPT-5.5 与 Gemini-3.1-Pro 上保留 43–46% 的原始 ASR。
  - 跨样本：保留 64–66% 的原始 ASR。
- **真实世界影响**：
  - 在 OpenClaw 默认 Discord 部署中，攻击者可利用带注入图像覆盖 `TOOLS.md`，后续诱导 `curl | bash` 执行恶意脚本，实现持久化权限提升。
  - 纯文本自适应注入在 GPT-5.5 上完全失败、Gemini-3.1-Pro 上仅 32% 成功；加入图像后分别达到 90% 和 100%。
- **防御评估**：
  - 无单一防御能在所有三个商用模型上把 ASR 降到接近零。
  - 防御提示效果依赖模型；图像处理不够稳定；OCR 类防御相对更一致，其中 `Unfiltered OCR + Sandwich` 将 ASR 分别降至 21%、6%、5%。

## 7. 优点

- **核心思路创新**：将攻击从“任务覆盖”重构为“响应前缀控制”，显著降低对图像文本是否被视为权威指令的依赖。
- **黑盒与自适应**：不依赖受害者模型权重、梯度或 logits，适用于 API-only 商用 VLM。
- **现实威胁建模**：同时满足真实良性提示、仅图片注入、精确目标输出、黑盒有效性四个要求，比多数先前工作更贴近实际部署。
- **攻击库设计**：可复用历史成功注入，降低搜索成本，提高攻击效率。
- **端到端验证**：不仅做了标准基准测试，还在真实 OpenClaw Discord 环境中完成攻击，展示了持久化和远程代码执行风险。
- **实验全面**：涵盖多个前沿模型、消融、迁移性、渲染因素和多种防御，证据充分。

## 8. 不足与局限

- **成本较高**：单个样本约需 1600 次受害者查询，API 成本显著，可能影响可复现性和大规模部署。
- **防御评估不完整**：攻击图像只在无防御模型上优化，未测试攻击者针对防御进行自适应优化后的效果，可能低估真实风险。
- **未覆盖某些部署设置**：未测试图像放在工具返回（tool return）中的场景；作者假设该设置下攻击效果会较弱。
- **数据与场景限制**：良性任务主要来自 DocVQA 文档图像，PII 为合成画像；真实世界多样性可能更复杂。
- **攻击者知识假设**：攻击不利用系统提示、聊天历史或 harness 等信息，但真实攻击者可能知晓并利用这些信息进行更强攻击；文中未对此扩展分析。
- **模型时效性**：结果基于评估时的前沿模型版本，模型更新后攻击成功率可能变化。
