## 摘要
LLM智能体在来自系统提示、用户、记忆和工具的指令之间进行仲裁，但不能假定这种仲裁会强制执行信任边界。我们发现一个识别-强制差距：来源格式特征（角色模板位置、通道元数据、格式线索）可以从模型激活中线性解码，而且模型在被提示时能够明确识别伪造的权威，然而某些配置仍会产生冲突的工具调用。我们在这种特定的“可解码来源格式+可口头化检测”意义上使用“识别”；交叉探针对照表明，这并非统一的抽象信任表征。该差距并非模型权重的固有属性。限制性策略和多样化提示能在相同模型上消除执行，而宽松配置及特定提示-模型组合则导致确定性失败。在一项模型集群评估中（权威欺骗：涵盖6家供应商的46个模型端点，包括开放权重；记忆冲突：48个模型），在多样化新型攻击下的平均执行率为1.21% [0.5%-2.1%]（基于29个模型的14,294次欺骗试验的模型聚类置信区间），但脆弱性集中在可复现单元中，并随部署窗口而变化（窗口内每个指纹范围最高达47个百分点）。提示层防御同样无法跨模型和自适应表述实现泛化。因此，我们将模型的自我仲裁视为一种能力而非安全边界，并实现了一个外部引用监视器，其结合了经认证的来源路由与能力门控的工具执行。它能确定性地拒绝所有经过测试的伪造、篡改、重放和未签名请求，同时保留合法操作。一个独立的自适应红队发现了一个实现缺陷（一处此后已修补的时钟偏移准入），而非密码学绕过。安全智能体需要外部强制，而不仅仅是更好的识别。

## Abstract
LLM agents arbitrate among instructions from system prompts, users, memory, and tools, but this arbitration cannot be assumed to enforce trust boundaries. We identify a recognition-enforcement gap: source-format features (role-template position, channel metadata, formatting cues) are linearly decodable from model activations, and models can explicitly identify forged authority when prompted, yet some configurations still produce the conflicting tool call. We use "recognition" in this specific decodable-source-format-plus-verbalized-detection sense; crossed-probe controls show it is not a unified abstract trust representation. The gap is not an immutable property of model weights. Restrictive policies and diverse prompts can eliminate execution on the same models, while permissive configurations and particular prompt-model pairs yield deterministic failures. Across a fleet evaluation (authority spoofing: 46 model endpoints across 6 vendors including open-weight; memory conflict: 48 models), average execution under diverse novel attacks is 1.21% [0.5-2.1%] (model-clustered CI over 14,294 spoofed trials from 29 models), but vulnerability is concentrated in reproducible cells and shifts across deployment windows (up to 47pp within-window per-fingerprint range). Prompt-layer defenses likewise fail to generalize across models and adaptive formulations. We therefore treat model self-arbitration as a capability rather than a security boundary and implement an external reference monitor combining authenticated source routing with capability-gated tool execution. It deterministically rejects all tested forged, tampered, replayed, and unsigned requests while preserving legitimate operations. A separate adaptive red-team found one implementation flaw (a since-patched clock-skew admission), not a cryptographic bypass. Secure agents require external enforcement, not merely better recognition.

- **整体含义**：该差距不是模型权重的固有属性，而是依赖于提示、策略、模型、解码条件和部署快照的配置组合。因此，模型自我仲裁只能被视为一种“能力”（capability），不能作为安全边界（security boundary）。安全智能体必须依赖外部强制执行（external enforcement），而不是仅仅提高识别能力或使用提示层防御。

## 6. 论文的主要结论与发现

- **识别–强制差距核心成立**：来源格式信息在残差流中近天花板可解码，且模型可口头识别伪造权威，但在宽松配置下仍执行冲突工具调用；该分离是配置依赖的，不是模型固有属性。
- **漏洞具有针对性、异质性和时间不稳定性**：绝大多数模型在多样化新提示下平均执行率仅 1.21%，但个别提示–模型组合可达 40–100%；不同部署窗口、后端指纹间漂移高达 47pp，同一模型名可能完全反转。
- **提示层防御不可作为安全边界**：关键词防御可被平静重述绕过；机制匹配和通用防御在模型间呈双分离；自适应攻击者能以低查询预算突破最强调提示防御；某些防御甚至产生反效果。
- **外部强制执行有效**：HMAC 签名+能力门控+源路由在所有测试的确定性攻击变体中实现 0% 绕过（0/900），并保留合法吞吐量（64–100%）；内容移除消除全部渠道伪造漏洞。
- **边界是语义授权**：经认证的用户或代表消息仍可诱导特权请求，除非独立约束于有作用域的能力；混淆代理（confused deputy）通过合法签名内容仍可导致模型尝试执行，但若动作未关联令牌则外部执行层阻断。
- **来源表征早于对齐**：OLMo-2 基座模型已有 AUC=1.0 的来源位置方向，对齐训练重新组织深层几何但不创造该表示；提示层与内部干预均无法可靠移动执行决策。

## 7. 优点

- **规模大、覆盖广**：46/48 个模型、6 家供应商、>256k 试验，多供应商、多代际、开放权重与 API 结合。
- **多证据类型整合**：将线性探针、强制反思、思维链分析和激活干预与大规模行为评估系统连接，形成有层次的证据链。
- **统计严谨性**：识别并修正朴素试验级 CI 的不足（模型聚类 bootstrap 宽 4.5×），采用提示级单元、ICC 分解、前瞻性 held-out 协议。
- **透明度高**：公开全部代码、数据、攻击提示；披露静默路由失败并重采集；区分证明类型（确定性功能正确 vs. 经验鲁棒性）；详细的 claim ladder。
- **实践相关性**：给出部署指南、滚动窗口协议、最坏情况绑定、检查清单，并清晰界定外部强制执行的局限（语义授权边界）。
- **伦理处理**：良性代理任务、90 天披露窗口、拒绝控制中验证后不发布有害内容。

## 8. 不足与局限

- **探针解释局限**：源标记可解码可能主要是格式/位置特征而非抽象权威；全维度近天花板准确率在样本量远小于维度（N≪d）下可能是伪影，尽管 PCA 降维后仍保持。
- **因果干预的因果结论弱**：7 个模型中仅 2 个（Llama-3.3-70B, DeepSeek-R1-32B）通过拒绝方向正控制验证，其余模型对所有方向（包括拒绝）均无移动，不能解释；执行决策对单方向加性引导整体不敏感。
- **API 时间与部署依赖**：所有行为速率是 2026 年 1–8 月窗口快照，模型端点行为会变化；部分模型名称可能过时，结果不便复现。
- **实验设计混杂**：held-out 评估同时改变提示新颖性和系统提示严格性，虽后期用 2×2 析因拆解，但主要解读仍受混杂影响。
- **无正式预注册**：前瞻性 held-out 没有独立时间戳预注册，不能完全排除偏差。
- **单一作者，独立复现缺失**：作者声明同伴预印本未被独立复制。
- **资源限制**：无法获得 BF16 70B 激活配对捕获，SAE 精度混杂只能依赖共享精度控制；部分桥架模型因框架不支持被排除。
- **防御评估范围**：外部强制执行只验证确定性检查正确性，未测试密钥泄露/伪造、并发 TOCTOU、解析差异、拒绝服务等生产级威胁。
- **可推广性受限**：良性代理到真实有害任务的转移在 API 上是条件性的，具模型依赖；作者仅将安全相关性视为结构推断。
- **部分行为分类主观**：例如 Claude 模型的文本意图 vs. 结构化调用边界依赖解析严格性，可能高估/低估不同部署下的风险。
