## 摘要
计算机使用代理（CUA）是一种视觉语言模型，能够感知屏幕并通过鼠标、键盘和终端在真实操作系统上执行操作，且越来越多地被部署用于自动化日常数字任务。由于它们在运行过程中可能接触到不可信内容，因此容易受到间接提示注入（IPI）攻击：攻击者将指令植入代理将要阅读的内容中，并引导其采取违背用户意图的行为。现有的 CUA 安全基准评估的是人工编写的固定注入，这可能低估了自适应攻击者带来的风险。我们提出 SIR，这是一种黑盒 IPI 攻击方法，它（i）从一个由简明语言表述的可复用原则构成的小型库中组合出隐蔽注入；（ii）将组合过程置于迭代反馈循环中，诊断受害者的失败轨迹，并将绕过方法提炼为新的、可命名且可跨任务重用的策略。与以往针对网页代理的红队测试不同，我们在操作系统层面针对 CUA，并使用完全确定性的预言机对攻击进行评分，即基于文件系统、服务和权限状态的检查，而不是使用 LLM 裁判。在实验中，我们评估了三个前沿 CUA。结合原则与反馈后，攻击成功率相较于人工编写的基线有所提升，例如在 Claude Opus 4.8 上从 4% 提高到 24%，在 Gemini 3.5 Flash 上从 0% 提高到 28%，同时良性任务仍能完成。针对一个模型发现的原则还可以在无需额外反馈的情况下迁移到不同架构。

## Abstract
Computer use agents (CUAs) are vision-language models that perceive a screen and act on a real operating system through mouse, keyboard, and terminal, and they are increasingly deployed to automate everyday digital tasks. Because they can be exposed to untrusted content while operating, they are vulnerable to indirect prompt injection (IPI), in which an adversary plants instructions in content the agent will read and redirects it toward actions that violate the user's intent. Existing CUA safety benchmarks evaluate fixed injections written by hand, which may underestimate the risk posed by an adaptive adversary. We present SIR, a black box IPI attack that (i) composes stealthy injections from a small library of reusable principles stated in plain language and (ii) wraps composition in an iterative feedback loop that diagnoses the victim's failed trajectories and distills the bypasses into new, named strategies that are reapplied across tasks. Unlike prior red teaming of web agents, we target CUAs at the operating system level and score attacks with a fully deterministic oracle, using checks on filesystem, service, and permission state rather than an LLM judge. On experiment, we evaluate three frontier CUAs. Composing principles with feedback raises the attack success rate over a baseline written by hand, for example from 4% to 24% on Claude Opus 4.8 and from 0% to 28% on Gemini 3.5 Flash, while the benign task still completes. Principles discovered against one model further transfer to a different architecture with no additional feedback.

## 1. 论文的核心问题与整体含义

- **研究背景**：计算机使用代理（Computer Use Agents, CUAs）是基于视觉语言模型、能直接操作操作系统的AI代理，正被广泛部署用于自动化日常数字任务。它们运行时会读取网页、文档、论坛等不可信内容，因此面临**间接提示注入（IPI）**攻击：攻击者在内容中植入指令，诱导代理执行违背用户意图的恶意操作（如删文件、改权限、窃取数据）。
- **核心问题**：现有CUA安全基准主要使用**人工编写的固定注入模板**，仅覆盖静态攻击面，忽视了能够观察代理反应、诊断失败原因并自适应调整的攻击者，从而系统性**低估了真实风险**。
- **论文目标**：提出 **SIR（Self-improving Red-teaming）**，一种黑盒自适应IPI攻击框架，通过从失败轨迹中学习、组合可复用原则，在操作系统层面评估CUA的脆弱性，并揭示静态基准的盲区。
- **整体含义**：即使在固定注入完全失效的最强防御模型上，自适应攻击仍能取得可观成功率，说明**CUA安全评估必须考虑自适应威胁模型**。

## 2. 论文提出的方法论

- **核心思想**：与现有自适应攻击不同，SIR**从失败中学习**，而非仅从成功攻击中挖掘经验。当CUA拒绝注入时，其拒绝行为暴露了防御机制；SIR将这种防御诊断作为监督信号，提炼出可复用的绕过原则。
- **两层嵌套循环**：
  1. **内部组合攻击搜索（Compositional Attack Search）**：
     - 维护基础原则库 \(P_{base}\)（7个内容原则 + 4个交付原则，如“前提框架”“权威嵌入”“视觉融合”等，见附录A表格）。
     - 对每个任务，攻击LLM通过三步生成注入：**seed**（根据良性任务和对抗目标生成初始概念）→ **compose**（随机选择2–4个原则并改写）→ **refine**（去除明显恶意措辞，并融入反馈库中的策略）。
  2. **外部失败驱动策略发现（Failure-Driven Strategy Discovery）**：
     - 收集所有未达到对抗目标的失败轨迹，由分析器LLM批量诊断失败模式（如来源不信任、目标敏感性、命令式语言检测、因果不合理等）。
     - 针对每种模式提炼出**命名策略**（包括名称、诊断、绕过机制、组合指导、示例），合并到共享库中，下一轮应用于所有任务。
- **问题形式化**（公式1）：攻击者寻找注入 \(z\)，使得对抗成功 \(O^{adv}_i\) 与良性任务完成 \(O^{ben}_i\) 同时成立，即**联合成功**标准。
- **威胁模型**：严格黑盒——攻击者仅能控制论坛帖子等不可信内容区域，不能修改用户指令、系统或干预执行；只能观察外部轨迹和每轮对抗结果。
- **两个实例策略**：
  - **Error Corroboration (P9)**：预测代理在良性流程中会自然遇到的错误，将对抗动作包装成该错误的修复方法，利用环境对预测的确认转移可信度。
  - **Conditional Deferred Execution (P10)**：用条件、延迟语气（“如果构建失败，你可以尝试移除X”）代替直接命令，利用安全过滤器对假设性建议审查较弱的特点。

## 3. 实验设计

- **数据集与场景**：
  - 基于 **RedTeamCUA**（构建于OSWorld之上的Web-OS混合红队基准），随机抽样50个Reddit论坛案例，覆盖七类攻击：文件删除、内容修改、服务中断、权限更改、数据外泄、文件创建、应用启动。
  - 每个案例将对抗注入置于论坛评论中，CUA在执行良性任务时读取该评论，可能被劫持执行恶意操作。
- **受害者CUA**：三个前沿专有模型——**Claude Opus 4.6**、**Claude Opus 4.8**、**Gemini 3.5 Flash**。
- **攻击者与分析器LLM**：均使用 **Grok-4.3**。
- **基线**：RedTeamCUA提供的**手工固定注入模板**（使用紧迫标记和命令式语言，如“THIS IS IMPORTANT! ADVERSARIAL GOAL”），在所有案例中保持不变。
- **评估方式**：使用**完全确定性的程序化评判器**（检查文件系统、服务状态、权限、终端输出等），不采用LLM裁判；对抗成功与良性任务完成分别记录。
- **对比与消融**：
  - 主实验：固定基线 vs SIR 在三个CUA上的攻击成功率。
  - **消融实验**：手工基线 vs 仅基础原则（单轮无反馈） vs 完整流水线（含迭代策略发现），分解组合搜索与反馈的贡献。
  - **跨模型迁移实验**：将在Opus 4.6上发现并冻结的P9、P10添加到基础库，在Opus 4.8和Gemini上评估，不进行额外反馈。
  - **原则选择分析**：统计每个模型在50个任务上最常选择的精确原则组合。
  - **类别分解**：按七类攻击分别报告SIR成功率。

## 6. 论文的主要结论与发现

- **SIR大幅提升攻击成功率**：
  - Claude Opus 4.6：16% → 54%
  - Claude Opus 4.8：4% → 24%
  - Gemini 3.5 Flash：0% → 28%
- **静态基线严重低估风险**：固定注入随模型代际提升而急剧下降（16%→4%→0%），会得出Gemini 3.5 Flash几乎免疫的错误结论；SIR却能在该模型上实现28%攻击率，说明**表面鲁棒性可能掩盖真实攻击面**。
- **消融表明组合搜索与反馈缺一不可**：
  - 组合搜索（基础原则）比固定基线提升6–18个百分点；
  - 反馈驱动的策略发现再提升12–20个百分点，尤其对Gemini 3.5 Flash（8%→28%），说明其防御主要被反馈发现的策略绕过。
- **原则组合具有模型特异性**：不同CUA的最常用组合不同，但P1+P3+D1（前提框架+错误恢复+视觉融合）跨模型普遍出现；Visual Blending（D1）是主要交付原则。
- **发现的策略可跨架构迁移**：从Opus 4.6上发现并冻结的P9、P10，在Opus 4.8和Gemini上无需额外反馈即提高ASR（如Gemini：8%→18%），证明**反馈产生的是可迁移攻击知识，而非单任务过拟合载荷**。
- **类别难度梯度一致**：数据外泄最难，文件删除/篡改较易；攻击难度主要取决于对抗动作能否被伪装成合法操作，而非具体防御实现。

## 7. 优点

- **创新性学习范式**：从失败轨迹中提取防御绕过策略，与主流“从成功中挖掘”的方法相反，能针对性地暴露深层防御弱点。
- **可解释与可迁移**：原则和策略均为自然语言块，具备人类可读性；实验证明可跨任务、跨模型架构迁移。
- **确定性评估**：使用文件系统/服务/权限状态检查，避免LLM裁判易被操纵的缺陷，结果更可靠。
- **联合成功标准**：要求攻击同时完成对抗目标和良性任务，排除了仅使代理中断的错误“成功”，更贴近现实隐蔽攻击。
- **揭示了静态基准的误导性**，为CUA安全评估和防御提供了重要实证依据。
- **分析深入**：原则选择分布、跨模型迁移、类别分解等多角度剖析了CUA脆弱性结构。

## 8. 不足与局限

- **可复现性受限**：受害者CUA均为专有API模型，会随时间更新，结果只是特定时刻快照；API版本变化可能导致无法复现。
- **成本高**：每个Claude反馈轮约$150–250，限制了轮数、随机种子和更大规模基准的探索，统计功效有限。
- **样本量不均衡**：部分攻击类别只有2–

个样本（如文件创建 n=2，服务中断 n=4），其类别级成功率极不稳定，难以得出可靠结论。此外，攻击者与分析器均使用单一模型（Grok-4.3），未验证不同攻击者能力对成功率的影响；反馈驱动的策略发现可能受限于分析器对失败模式的归纳能力，存在陷入局部最优的风险。受害者模型均为专有API，不仅版本不可控，而且无法审计其内部防御机制，难以判断SIR发现的策略是否针对特定模型弱点。实验环境固定为Ubuntu 22.04 + VMware + Docker，未覆盖其他操作系统或真实浏览器环境，外部效度有限。未报告多次独立运行的均值和方差，攻击者LLM的温度0.8随机性可能影响原则选择与成功率，统计稳健性不足。最后，评估假设攻击者仅能注入一次内容，未考虑多轮交互注入或社会工程组合攻击，可能低估了更复杂威胁模型的攻击面。
