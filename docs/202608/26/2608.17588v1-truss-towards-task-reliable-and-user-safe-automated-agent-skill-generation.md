## 摘要
智能体技能将可复用的自然语言流程与可执行资源打包在一起，使软件智能体无需模型适配即可获得任务特定能力。自动生成此类技能可以提升任务表现，但仅从候选技能的作品或最终任务结果来评估，无法确定装备该技能的智能体将执行哪些动作以及这些动作会产生哪些副作用。我们提出 TRUSS，一个以证据为导向的框架，用于生成功能有效且安全可靠的智能体技能。TRUSS 首先依据来源和领域证据检查功能声明，同时根据九个预定义安全属性评估完整制品。通过这一静态关卡筛选的候选技能由影子智能体在可控执行环境中加载，其中代理工具将请求的动作暴露给策略执行，并将其结果记录为保留溯源信息的执行轨迹。功能失败和属性违规会被回溯到造成问题的技能内容，并用于指导迭代优化。我们在 168 个 SkillInject 制品、155 个 SkillSafetyBench 案例以及 SkillGenBench 的全部 187 个任务上评估 TRUSS。TRUSS 在漏洞检测中实现了 100.00% 的精确率和召回率。修复将攻击成功率从使用 GPT 5.5 时的 38.71% 降至 19.35%，从使用 GPT 5.4 时的 46.45% 降至 29.68%，且没有攻击回退。在技能生成方面，TRUSS 将任务有效率从无技能时的 17.11% 提高到 52.94%，同时将基准安全率从 50.80% 提高到 100.00%。这些结果表明，执行证据能够揭示制品检查所遗漏的行为失败，并引导技能生成朝着功能与安全联合验证的结果发展。

## Abstract
Agent Skills package reusable natural language procedures with executable resources, enabling software agents to acquire task specific capabilities without model adaptation. Automatically generating such Skills can improve task performance, yet evaluating a candidate solely from its artifact or final task outcome leaves unresolved which actions the equipped agent will perform and which side effects those actions will produce. We present TRUSS, an evidence guided framework for generating functionally effective and safety reliable Agent Skills. TRUSS first inspects functional claims against source and domain evidence while evaluating the complete artifact under nine predefined safety properties. Candidates admitted by this static gate are loaded by a shadow agent inside a Controllable Execution Environment, where brokered tools expose requested actions to policy enforcement and record their results as provenance preserving execution traces. Functional failures and property violations are linked back to the responsible Skill content and used to guide iterative refinement.   We evaluate TRUSS on 168 SkillInject artifacts, 155 SkillSafetyBench cases, and all 187 tasks in SkillGenBench. TRUSS achieves 100.00\% precision and recall in vulnerability detection. Repair reduces attack success from 38.71\% to 19.35\% with GPT 5.5 and from 46.45\% to 29.68\% with GPT 5.4, with zero attack regression. For Skill generation, TRUSS raises task effectiveness from 17.11\% without Skills to 52.94\%, while increasing the benchmark Security rate from 50.80\% to 100.00\%. These results show that execution evidence can expose behavioral failures missed by artifact inspection and can guide Skill generation toward jointly verified functional and safety outcomes.

## 1. 论文的核心问题与整体含义

- **研究背景**：LLM 智能体正从虚拟规划走向真实世界执行。开发者通过将可复用工作流、领域知识和工具集成打包为 **Agent Skills**，使智能体无需模型微调即可获得专门能力。技能生成目前主要依赖人工，成本高且难以保证跨任务可靠性。
- **核心问题**：自动化生成 Agent Skills 时，仅从最终产物（技能文件）或最终任务结果进行评估，无法获知装备该技能后智能体**实际会执行哪些动作、产生哪些副作用**。这导致功能有效性与安全可靠性之间无法被联合保证。
- **整体含义**：论文主张将技能生成视为一个**功能验证与安全验证的联合问题**，并提出需要引入动态执行证据来弥补静态制品检查的盲区，从而生成既“任务可靠”又“用户安全”的技能。

## 2. 论文提出的方法论

### 2.1 总体框架

- TRUSS 是一个由 **Generator（生成器）、Checker（检查器）、Refiner（优化器）** 组成的迭代框架。
- 生成器基于源材料生成候选技能包（包含自然语言指令和可执行资源），交给检查器。
- 检查器从**静态证据**和**运行时证据**两个维度评估候选技能。
- 优化器利用检查记录中的未解决义务和违规证据，对技能内容进行修改，生成新候选技能并重新进入完整检查流程，直至满足功能与安全要求或预算耗尽。

### 2.2 静态检查

- **功能声明检查**：提取技能描述与目标任务中的功能需求，将每条需求关联到可用来源证据或开放世界知识，判断该技能描述的操作在给定条件下是否可行。
- **九项预定义安全属性**（见表 1）：
  - P1 控制完整性：防止任务控制被指令操纵。
  - P2 访问边界：将能力使用限制在授权数据范围内。
  - P3 执行完整性：确保可执行行为来源可信。
  - P4 生命周期隔离：将状态限制在授权任务生命周期内。
  - P5 资源有界性：用场景预算约束环境副作用。
  - P6 证据完整性：使报告结果与执行证据一致。
  - P7 权限完整性：将后果性动作绑定到有效权限。
  - P8 组合完整性：在组合智能体组件间保持信任。
  - P9 交易安全：将外部交易限制在声明的策略内。
- 静态检查会根据技能声明与实际实现的能力范围确定哪些属性适用，并把需要运行时才能判断的项转化为明确的运行时义务。

### 2.3 运行时执行与证据记录

- 通过静态关卡的技能由**影子代理（shadow agent）**在**可控执行环境（CEE）**中加载并执行。
- CEE 提供**代理工具（brokered tools）**，每个请求动作都会先经过**中间断路器（Intermediate Breaker）**检查，再决定是允许进入一次性沙箱还是被阻断。
- 被阻断的动作仍会记录在轨迹中，使攻击意图可被观察。
- 所有工具交互被标准化为**执行事件**，绑定请求、返回结果、代理决策和因果父节点，形成**保留溯源信息的执行轨迹**。
- 运行轨迹同时用于功能完整性检查和九项安全属性的运行时评估。

### 2.4 形式化目标

- **功能有效性**：\(F(Sk;p) = \mathbb{E}_{x\sim p}[U(x,\tau_{Sk}(x)) - U(x,\tau_{\emptyset}(x))]\)，即技能带来的期望效用增益。
- **安全风险**：\(R_j(Sk;p) = \mathbb{E}_{x\sim p}[Z_j(x,\tau_{Sk}(x))]\)，其中 \(Z_j\) 为第 \(j\) 项属性是否被违反的指示函数。
- **联合目标**：\(Sk^* = \arg\max_{Sk \in S_G} \left[ F(Sk;p) - \frac{\lambda}{J} \sum_{j=1}^{J} R_j(Sk;p) \right]\)，在功能增益与安全风险之间取得平衡。
