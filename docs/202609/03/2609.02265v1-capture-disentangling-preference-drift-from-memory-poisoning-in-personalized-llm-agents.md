## 摘要
个性化语言智能体利用持久记忆来随时间适应用户，但同样的机制也带来了攻击面。当新信息与已存储的偏好冲突时，智能体必须区分真正的偏好漂移与暂时的情境变化、歧义或对抗性记忆投毒。我们将该问题形式化为潜在用户状态上的连续时间部分可观测决策过程，并说明仅基于新近性和来源的规则为何不足。CAPTURE 通过神经微分方程信念跟踪器、多时间尺度记忆账本、不确定性触发的澄清以及对所引用记忆的反事实审计来解决这种歧义。在来自 96 位用户的 480 个留出情节上，CAPTURE 取得了 71.5% 的胜率，而同等监督的基线为 69.3%，最强的启发式基线为 66.1%。它将固定策略投毒成功率限制在 11.5%，同时接受 83.5% 的真实偏好更新。在能够访问已发布权重的自适应攻击者下，攻击成功率上升至 24.7%，暴露出真实的适应性与安全性权衡。我们进一步在独立构建的基准上对冻结系统进行零样本评估，并回放从 40 位用户收集的两到三周的纵向交互历史。这些结果表明，显式建模偏好真实性可以同时提升记忆增强型 LLM 智能体的个性化能力与鲁棒性。

## Abstract
Personalized language agents use persistent memory to adapt to users over time, but the same mechanism creates an attack surface. When new information conflicts with stored preferences, an agent must distinguish genuine preference drift from temporary context shifts, ambiguity, or adversarial memory poisoning. We formulate this problem as a continuous-time partially observable decision process over a latent user state and show why rules based only on recency and provenance are insufficient. CAPTURE addresses this ambiguity with a neural differential-equation belief tracker, a multi-timescale memory ledger, uncertainty-triggered clarification, and counterfactual auditing of cited memories. On 480 held-out episodes from 96 users, CAPTURE achieves a 71.5% win rate, compared with 69.3% for an identically supervised baseline and 66.1% for the strongest heuristic baseline. It limits fixed-policy poisoning success to 11.5% while accepting 83.5% of genuine preference updates. Under an adaptive attacker with access to the released weights, attack success rises to 24.7%, exposing a real adaptation-security tradeoff. We further evaluate the frozen system zero-shot on an independently constructed benchmark and replay longitudinal interaction histories from 40 users collected over two to three weeks. These results suggest that modeling preference authenticity explicitly can improve both personalization and robustness in memory-augmented LLM agents.

## 1. 论文的核心问题与整体含义

- **研究动机**：个性化语言智能体通过持久记忆在数周内适应用户，但记忆本身成为攻击面。当新信息与已存储偏好冲突时，智能体难以区分以下四种情况：
  - 用户真实的偏好漂移（如升职后希望简短总结）；
  - 临时上下文切换（如站会要简洁、设计评审要详细）；
  - 良性噪声（讽刺、笔误、弱证据）；
  - 对抗性记忆投毒（检索文档、共享文件或工具输出中的恶意指令）。
- **核心歧义**：论文将以上困难称为 **“偏好-真实性歧义”**（preference-authenticity ambiguity）。传统方法只能二选一：
  - 个性化管线把一切历史当作真实，从而可被注入内容操纵；
  - 注入防御拒绝一切非可信来源，但会阻止合法用户通过正常渠道更新偏好。
- **整体含义**：论文主张**把真实性作为潜在变量进行推断**，而不是预先假设。通过显式建模偏好更新过程中的不确定性，可以同时提升个性化能力与抗投毒鲁棒性。

## 2. 论文提出的方法论

CAPTURE 由四个核心组件构成，整体路径为：事件提取 → 真实性门控 → 多时间尺度账本 → 安全约束选择与因果审计。

### 2.1 偏好假设提取
- 使用 **Qwen2.5-3B 模型 + LoRA 适配器**，在模式约束解码下输出结构化元组：
  \[
  H_t = \{\text{claim}, \text{direction}, \text{scope}, \text{timescale}, \text{confidence}, \text{provenance}\}
  \]
- 训练目标为交叉熵加弃权惩罚项 \(L_{\text{ext}} = \text{CE}(H_t, \hat{H}_t) + \omega_{\text{abs}}\Omega(\hat{H}_t)\)，使模型对无偏好信号的事件学会弃权（约七成事件无偏好内容）。

### 2.2 真实性门控
- 维护连续时间潜在信念 \(h_t\)，通过**神经微分方程**在事件间隔中演化：
  \[
  \frac{dh(t)}{dt} = f_\theta(h(t))
  \]
  其中 \(f_\theta\) 为三层 MLP，时间只通过积分区间 \(\Delta t\) 进入。事件到达时使用 GRU 离散更新。
- 门控输出六类动作的概率分布：保留、添加、窄化范围、修订、隔离（quarantine）、询问。
- 当动作分布的香农熵超过阈值 \(\eta = 1.24\) nats（按每 12 轮最多询问 1 次设定），触发**澄清问题**。
- 理论保证：附录定理 2-4 表明：
  - 仅依赖新近性和来源的规则误差下界为 \(1 - \delta_\varphi\)；
  - 条件化完整历史不会更差，并在一定条件下严格更优；
  - 有界成本澄清可扩大可达误差区域。

### 2.3 多时间尺度账本
- 记忆节点按三类时间尺度分层：
  - **稳定层**（stable）：\(\gamma_s=0.01\)/天，对应月份级变化；
  - **上下文层**（contextual）：\(\gamma_c=0.1\)/天，对应领域/项目偏好；
  - **瞬态层**（transient）：\(\gamma_g=0.5\)/天，对应会话内目标。
- 节点置信度随最后确认时间衰减：\(c_0 \sigma(h_t) e^{-\gamma(t-t_0)}\)。
- 覆盖稳定节点需要多次高置信证据，防止一句话重定义用户。
- **隔离**（quarantine）是状态而非层：隔离节点不可检索，14 天后若未获确认则被驱逐。
- 作用：在上下文切换时能同时保留两个有效信念，而不是错误覆盖。

### 2.4 安全约束选择与因果审计
- 选择器在候选响应中最大化个性化效用与安全风险之差：
  \[
  y^\star = \arg\max_{y \in Y} [\alpha r_p(y) - \beta r_s(y)] \quad \text{s.t. } r_s(y) \le \tau_{\text{safe}}

## 3. 实验设计

### 3.1 基准：D-PREFGUARD
- 规模：**2,400 个纵向情节**，每个 12-20 轮，来自 480 个合成用户；其中 **480 个情节（96 用户）为留出测试集**。
- 五个轨道：
  - T0：静止偏好（任何更新都算误报）；
  - T1：四种真实漂移（突变、渐变、反复、上下文切换）；
  - T2：良性噪声（讽刺、笔误、弱证据）；
  - T3：三类污染（间接注入、投毒摘要、同源写入）；
  - T4：个人效用与全局安全冲突。
- 种子来源：PRISM、PersonalLLM、LaMP 的用户画像；训练/开发使用 Qwen2.5-72B 和 Mixtral-8x22B 生成，测试使用 Llama-3.1-70B 生成（模型族隔离）。

## 6. 论文的主要结论与发现

- CAPTURE 在 D-PREFGUARD 上取得 **71.5% 胜率**，超过最强启发式基线 StateMem（66.1%）和监督匹配 Transformer（69.3%）。
- **固定策略投毒成功率仅 11.5%**，同时接受 **83.5%** 真实更新；Provenance-only 投毒 20.0% 但真实更新接受率只有 74.1%，说明 CAPTURE 在双轴上同时占优。
- **自适应攻击**（可访问已发布权重）使 CAPTURE 成功率升至 **24.7%**，此时 Provenance-only（22.1%）在安全性上与之无显著差异，CAPTURE 的优势主要在保持 83.5% 遵守率。
- **架构 vs 监督**：监督匹配 Transformer 解释了大部分提升；差异缩小到 2.2 个百分点胜率、4.4 个百分点投毒（显著），并将优势定位在账本和连续时间更新。
- **上下文切换**上，CAPTURE 在 71% 切换点选择“窄化范围”而不是覆盖，而 StateMem 仅 4%。
- 外部评估显示优势减弱但基本保持：真实用户回放胜率高 4.5 点，HorizonBench 矛盾解决率 0.72 vs 0.65。

## 7. 优点

- **形式化贡献**：将偏好-真实性歧义建模为连续时间部分可观测决策过程，并给出理论下界与澄清条件，而非纯经验修补。
- **多时间尺度账本**：有效处理上下文切换和反复漂移，避免单一记忆覆盖。
- **不确定性触发澄清**：在不增加过高交互成本的前提下减少错误写入。
- **反事实审计**：为可解释性提供量化指标，而非依赖注意力或检索排序等不可靠信号。
- **实验设计严谨**：分割测试按用户/主题/生成模型隔离；报告自适应攻击而非仅有利数据；用独立构建基准和真实用户回放缓解“学习自身生成器”的质疑。
- **诚实报告局限**：明确声明自适应攻击下安全优势不显著，并给出上下文。

## 8. 不足与局限

- **自适应攻击下安全性优势不稳健**：与 Provenance-only 的差异仅 2.6 个点，p=0.29，未达显著；CAPTURE 的核心安全优势主要来自固定策略和部分攻击场景。
- **外部有效性有限**：D-PREFGUARD 是合成基准，绝对数字不应视为部署估计；HorizonBench 虽有独立构建，但轨迹仍为模拟的。
- **用户研究规模小**：仅 40 人，无法支撑子组分析；受控攻击为非独立生成，只能测试污染鲁棒性的迁移，不能测试独立攻击。
- **澄清机制过于理想化**：定理假设对称错误通道（固定 ε），实际中澄清成本与准确性需重新验证；用户回放中 ε=0 属 oracle-assisted，不反映真实部署。
- **训练数据偏差风险**：虽然分割隔离了生成模型，但所有训练标签来自同一生成程序；独立人工标注一致率 83.6%，仍可能存在系统性偏差。
- **隔离/澄清预算等超参依赖自身验证集**：在外部数据上未重新调优，可能存在过拟合。
- **无法处理权重级投毒**：仅针对文本记忆层，不对抗模型权重篡改。
- **一些外部评估差异不显著**：HorizonBench 的 belief revision 差异 0.01（p=0.27），replay poisoning 差异 -5.0 点（p=0.064），架构泛化增益在部分指标上未被证明。
