## 摘要
利用稀疏自编码器（SAE）进行引导控制，为在无需重新训练的情况下调整大语言模型行为提供了一种轻量的推理时路径。通过暴露稀疏且可解释的特征，SAE 引导为安全控制提供了一种有前景的接口，可将有害续写引向拒绝回答。然而，我们观察到复杂包装提示仍可能削弱现有 SAE 引导方法在有害提示上的效果。为系统评估这一失效模式，我们构建了广义隐蔽指令安全评估（GUISE）数据集，其中包含带有复杂包装的有害提示。现有单向 SAE 引导方法无法在有害提示上稳定触发拒绝回答，这表明当有害续写路径仍处于活跃状态时，仅增强拒答可能力度不足。为此，我们提出拒答增强抑制性引导方法（REINS），在同一 SAE 特征空间中抑制有害续写特征并增强安全拒答特征。在 GUISE 和其他数据集上的实验表明，先前方法要么干预过弱，要么仅通过模型崩溃获得表面安全；而 REINS 能大幅减少有害响应，显著提升安全拒答率，并在很大程度上保持通用能力。

## Abstract
Steering with Sparse Autoencoders (SAEs) offers a lightweight inference-time path for adapting the behavior of large language models without retraining. By exposing sparse and interpretable features, SAE steering provides a promising interface for safety control that guides harmful continuations toward refusal. However, we observe that complex wrappers can still undermine existing SAE steering methods on harmful prompts. To evaluate this failure mode systematically, we construct Generalized Undercover Instruction Safety Evaluation (GUISE), a dataset of harmful prompts with complex wrappers. Existing single direction SAE steering methods do not reliably produce refusals on harmful prompts, suggesting that refusal enhancement alone can be too weak when the harmful continuation path remains active. This motivates us to propose Refusal-Enhanced INhibitory Steering (REINS), which suppresses harmful continuation features and enhances safe refusal features in the same SAE feature space. Experiments on GUISE and other datasets show that prior methods either intervene too weakly or achieve only apparent safety through collapse, while REINS substantially reduces harmful responses, markedly improves safe refusals and largely preserves general capabilities.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）需要在推理时适应安全边界，但全量重训或永久权重编辑成本高、副作用大。基于稀疏自编码器（SAE）的推理时引导提供了一种轻量、可解释的替代路径。
- **核心问题**：现有 SAE 引导方法通常只朝单一方向（如增强“拒绝”特征）干预，在面对**复杂包装的有害提示**（即把有害目标隐藏在角色扮演、领域借口、格式约束或任务描述中）时，往往无法可靠触发拒绝。原因是仅增强拒绝信号不足以压制仍然活跃的有害续写路径。
- **整体含义**：安全控制需要同时“抑制有害续写”和“增强安全拒绝”，且两者应在同一 SAE 特征空间中协同完成，而非依赖单一控制信号或通过输出退化（collapse）获得表面安全。

## 2. 方法论

### 2.1 GUISE 数据集构建
- **目的**：系统评估复杂包装下的隐蔽有害请求。
- **结构**：三层分类体系：5 个有害大类（仇恨、犯罪、暴力、色情、自伤）→ 15 个子类 → 45 个具体场景，每场景 20 个样本，共 900 个包装有害提示。
- **样本配对**：每个包装有害提示配有一个匹配的安全提示，保持相同表层语境但移除有害目标，用于控制实验。
- **构建流程**：使用 Gemini-3.1-Pro 生成种子和包装，经 Qwen3.5-4B-Base 生成响应，GPT-4o-mini 初审，Claude Haiku 4.5 复审，分歧交由人工裁决。最终有害响应率约 90.3%。

### 2.2 REINS 方法
REINS 在同一 SAE 特征空间中协调两个互补控制器：

- **Harm-Inhibit（有害抑制）**
  - **逐提示选择特征**：先让未引导模型生成早期前缀，暴露当前包装下已开始实现的有害续写路径。
  - **特征排序**：对每个 SAE 特征计算梯度×激活的归因值（Eq.1），取正支持并施加层深度权重和输出机制惩罚（Eq.2），保留 Top-K 特征（Eq.3）。
  - **干预**：在生成的全部续写 token 位置，将这些特征置零。

- **Refusal-Enhance（拒绝增强）**
  - **固定校准特征集**：基于 16 个拒绝指令-回答对（4 个拒绝指令 × 4 个固定拒绝答案）计算拒绝回答 token 上的平均激活。
  - **双重负样本过滤**：与中性指令回答和校准集中有害续写的激活对比，取差值并过滤通用助手脚手架/有害特征（Eq.4-6）。
  - **干预**：在前 \(M_R\) 个生成 token 位置，向选定的固定特征添加校准强度值。

- **联合干预（Eq.7）**
  - 对特征 \((l,j)\) 在 token 位置 \(t\) 的稀疏更新：
    - 若属于 Harm-Inhibit 区域：置零；
    - 若属于 Refusal-Enhance 区域（且不与 Harm-Inhibit 重叠）：加上 \(b^R_{l,j}\)；
    - 否则不变。
  - 两个控制器保持功能分离，重叠时以抑制优先。

- **REINS-Gate（门控扩展）**
  - 利用提示侧 SAE 平均激活向量 \(\mathbf{v}(x)\)，与校准得到的有害模式权重 \(\mathbf{w}_{\text{gate}}\) 计算余弦相似度得分。
  - 设定阈值 \(\tau\)，当得分 ≥ 阈值时才应用 REINS，否则保持模型原样，以降低对正常提示的附带影响。
  - 阈值通过校准扫描确定：在负样本误开率不超过预算 \(\beta\) 的前提下，最大化有害提示的开启率。

## 6. 主要结论与发现

- **GUISE 构成严格挑战**：Original 和 Random-SAE 的 HRR 约 90%，说明复杂包装显著削弱模型的安全倾向。
- **基线方法各有失效模式**：
  - Refusal-SAE 干预过弱；
  - SAE-SSV* 降低 HRR 但拒绝增益有限；
  - CorrSteer-A 通过崩溃获得部分安全假象。
- **REINS 优势明显**：
  - 在 Qwen3.5-4B-Base 上，HRR 从 90.3% 降至 26.3%，SRR 从 3.7% 升至 63.7%，CR 仅 2.7%（对比 CorrSteer-A 的 CR 20.3%）。
  - REINS-Gate 保持安全性能的同时，将 CE 从 26.4% 降至 0.1%，MMLU-Pro/GPQA 恢复至接近 Original。
- **外部迁移稳健**：REINS 在三个外部基准上均将 HRR 降到 7% 以下，SRR 保持在 70% 以上，且主要增益来自明确拒绝而非崩溃。
- **消融结论**：抑制和增强必须联合使用；单独抑制产生更多其他安全输出而非明确拒绝，单独增强无法阻断有害路径。
- **特征级证据**：Harm-Inhibit 高频选择集中于有害操作/私人数据语境；与 Refusal-Enhance 的固定特征几乎不重叠（Qwen3.5-4B 重叠率 0%，Qwen3.5-2B 0.0417%）。
- **总体结论**：SAE 安全引导应组合抑制有害支持与增强拒绝支持，而不是依赖单一特征方向。

## 7. 优点

- **双控制器设计新颖且合理**：在同一 SAE 空间中显式分离“阻断有害”与“推进拒绝”，避免了单一方向信号负担过重的问题。
- **GUISE 数据集填补空白**：针对复杂包装/隐蔽有害请求，提供含匹配安全对照、三层分类、自动+人工审核的高质量基准。
- **实验全面客观**：包含主评估、外部迁移、消融、特征审计、多法官验证、效率分析，结论可靠。
- **REINS-Gate 有效平衡安全与局部性**：几乎消除对正常提示的附带改变，同时保持有害提示上的安全增益。
- **可解释性强**：SAE 特征级的语义审计表明干预目标明确，不是盲目按关键词匹配。

- **模型覆盖有限**：受计算限制，主要实验限于 Qwen3.5-4B-Base 和 Qwen3.5-2B-Base，未在更大模型、更复杂指令微调模型或其他架构上充分验证。
