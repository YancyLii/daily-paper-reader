## 摘要
大型语言模型（LLMs）已被集成到复杂生态系统中（如代码智能体），而间接提示注入（IPI）攻击已成为其安全部署的关键障碍。攻击者利用 LLM 对“指令”与“数据”的不可区分性，通过恶意注入指令来操纵 LLM。然而，现有防御面临难以调和的安全-效用权衡：大多数护栏要么引入高延迟，要么遭受严重的过度拒绝。本文首先通过理论和实证证据证明，LLM 能够内在地将指令与数据分离。受此启发，我们提出 AEGIS（面向注入屏蔽的自适应集成护栏）。AEGIS 提取指令敏感投影器以识别恶意指令，并利用统一多层共识机制聚合网络深度上拓扑不同的信号。实证评估表明，与基线相比，AEGIS 在面对启发式和基于优化的攻击时均取得了显著的检测性能，凸显其缓解 IPI 的潜力。代码可在 https://github.com/xaddwell/AEGIS 获取。

## Abstract
Large Language Models (LLMs) have been integrated into complex ecosystems (e.g., Code Agents), while Indirect Prompt Injection (IPI) attacks have emerged as critical barriers to their safe deployment. Attackers exploit LLMs' indistinguishability between "instructions" and "data" to manipulate LLMs via maliciously injected instructions. Existing defenses, however, face an intractable safety-utility trade-off: most guardrails either incur high latency or suffer from severe over-refusal. In this paper, we first demonstrate that LLMs can separate instruction from data intrinsically with both theoretical and empirical evidence. Inspired by this insight, we propose AEGIS (Adaptive Ensemble Guard for Injection Shielding). AEGIS extracts instruction-sensitive projectors to identify malicious instructions and leverages a Unified Multi-Layer Consensus mechanism that aggregates topologically distinct signals across the network depth. Empirical evaluations show that AEGIS achieves remarkable detection performance against both heuristic and optimization-based attacks compared to baselines, highlighting its potential to mitigate IPI. Code is available at https://github.com/xaddwell/AEGIS

## 2. 方法论

### 2.1 核心思想

- **潜在流形假设**：
  - 预训练使知识表示 \(h_K\) 占据高维、高方差、高熵流形 \(M_K\)；
  - 指令微调（SFT）使指令表示 \(h_I\) 坍缩为低维、紧凑的算子子空间 \(M_I\)；
  - 谱范数满足 \(\|\Sigma_K\|_2 \gg \|\Sigma_I\|_2\)，因此检测注入等价于在高噪声知识背景中识别“指令信号”。
- **关键设计**：不依赖黑盒分类，而是在潜在空间中定位紧凑指令流形上的签名。

### 2.2 关键技术细节

- **指令敏感投影器（Instruction-Sensitive Projector）**：
  - 以 Fisher 准则形式优化投影方向 \(w^*\)，最大化指令与知识类中心距离，同时最小化指令类内方差：
    \[
    w^* = \arg\max_w \frac{(w^T(\mu_I-\mu_K))^2}{w^T\Sigma_I w}
    \]
  - 闭式解：\(w^* \propto \Sigma_I^{-1}(\mu_I-\mu_K)\)；
  - 采用 Ledoit-Wolf 收缩估计协方差；
  - 丢弃 \(\Sigma_K\)，避免压缩知识流形，专注于将指令流形“聚焦”为紧凑尖峰。
- **分布感知安全阈值校准（Distribution-Aware Safety Calibration）**：
  - 基于良性知识集投影分数的分位数设置阈值，保证误报率（FPR）不超过设定水平 \(\beta\)；
  - 阈值公式：\(b = -Q_{1-\beta}(\{w^{*T}h \mid h \in D_{\text{benign}}\})\)。
- **统一多层共识机制（Unified Multi-Layer Consensus）**：
  - 对所选层 \(l \in L_{\text{vote}}\) 的投影分数 \(S_l(x)\) 进行聚合，得到集成分数 \(S_{\text{ens}}(x)\)；
  - 支持两种模式：
    - 硬投票：\(\phi_{\text{hard}}(s)=I(s>b_l)\)，以投票数过阈值判定；
    - 软投票：对分数标准化后求和。
- **理论保证**：
  - 假设层间近似独立，利用 Hoeffding 不等式得到集成 FPR 指数上界；
  - 推导潜在鲁棒性半径：集成半径等于所有层半径的第 \(\Gamma\) 个次序统计量，即“中位数强度”而非最弱层。
