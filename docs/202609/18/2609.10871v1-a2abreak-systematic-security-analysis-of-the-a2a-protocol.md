## 摘要
Agent2Agent（A2A）协议目前由Linux基金会管理，是一项开放标准，使自主AI智能体能够跨组织边界相互发现、认证并委托任务。A2A旨在补充用于工具集成的模型上下文协议（MCP），正迅速成为多智能体生态系统的横向通信层。然而该协议的安全性尚未得到系统性分析。本文提出A2ABreak，首次对A2A协议进行严格的系统性安全分析。我们引入一个新颖框架，利用LLM辅助从自然语言规范中提取经过验证的有限状态机，基于929条形式化语句产生包含37个状态和76个转换的统一模型，并在完全合规假设下通过对抗性验证对该模型进行系统性推理，以发现协议级漏洞。我们的分析发现了11个新漏洞，每一个都可被符合规范的对手利用，且无需任何实现缺陷。这些发现包括：通过未受保护的上下文标识符进行跨客户端上下文注入、在委托链中因多跳身份丢失而导致的凭据收集，以及通过发布未经证实的能力声明的恶意代理进行数据外泄。A2ABreak在独立专家评审下达到73.3%的精确率和84.6%的F1值，而在同一规范上运行的零样本LLM基线产生了零个确认发现，表明显式的形式化基础对于可靠的协议安全分析是必不可少的。

## Abstract
The Agent2Agent (A2A) protocol, now governed by the Linux Foundation, is an open standard that enables autonomous AI agents to discover, authenticate with, and delegate tasks to one another across organizational boundaries. Designed to complement the Model Context Protocol (MCP) for tool integration, A2A is rapidly emerging as the horizontal communication layer of the multi-agent ecosystem. Yet the protocol's security has received no systematic analysis.   This paper presents A2ABreak, the first rigorous systematic security analysis of the A2A protocol. We introduce a novel framework that utilizes an LLM-assisted extraction of a verified finite-state machine directly from the natural-language specification, producing a unified model of 37 states and 76 transitions from 929 formalized statements, and then systematically reasons over this model to discover protocol-level vulnerabilities through adversarial verification, under a full-compliance assumption.   Our analysis uncovers 11 new vulnerabilities, each exploitable by a specification-compliant adversary without requiring any implementation flaw. Among the findings are cross-client context injection through unprotected context identifiers, credential harvesting via multi-hop identity loss in delegation chains, and data exfiltration through rogue agents advertising unattested capability claims.   A2ABreak achieves 73.3% precision and 84.6% F1 against independent expert review, while a zero-shot LLM baseline operating over the same specification produces zero confirmed findings, demonstrating that explicit formal grounding is essential for sound protocol security analysis.

## 2. 论文提出的方法论

A2ABreak 框架分为三个阶段，整体将自然语言协议规范转化为经过验证的有限状态机（FSM），再基于 FSM 进行对抗验证，以发现协议级漏洞。

### 2.1 Stage A：规范形式化

- 将 A2A 规范解析为机器可处理的正式语句语料。
- 采用**双通道语义分离**：
  - **结构提取通道**（A1）：提取 FSM 状态、数据约束、隐式转换等。
  - **行为提取通道**（A2）：提取含 RFC 2119 关键词（MUST/SHOULD/MAY）的行为规则。
  - 两个通道独立执行，避免定义与行为语义交叉污染。
- 通过对立统一（A3）与规范验证（A4）得到 **929 条经过验证的正式语句**。

### 2.2 Stage B：FSM 构建

- 六个协议阶段（发现、认证、启动、任务执行、中断、终止）分别独立构建 FSM。
- 解析跨阶段转换，最终合并为统一的 FSM。
- 通过确定性去重（D1）和语义去重（D2）进行剪枝。
- 最终得到 **37 个状态、76 个转换**，相对 929 条语句实现 **92% 的端到端压缩**。

### 2.3 Stage C：安全分析

- 在**完全合规假设**下（所有参与者都满足 MUST/SHOULD/MAY，实现正确，传输安全正常）进行漏洞发现。
- **候选发现**（C1）：检查缺少授权守卫、边界检查缺失、异常消息序列等。
- **对抗验证**（C2）：每个候选漏洞必须通过四个步骤：
  1. 攻击路径必须可由 FSM 中的有效状态和转换重构；
  2. 在完全合规条件下证明可执行；
  3. 确认没有任何规范规则阻止该攻击；
  4. 确认缺失的原语在整个规范中确实不存在。
- 所有 LLM 辅助步骤都使用领域专用约束语言，强制生成机器可验证的形式表示，避免自由文本幻觉。

## 6. 论文的主要结论与发现

- **11 个协议级漏洞**分布在发现、启动、任务执行、中断四个阶段，均可在完全合规条件下被利用。
- 代表性漏洞包括：
  1. **跨客户端上下文注入**：`contextId` 缺乏所有权绑定和访问控制，攻击者可注入任务到受害者上下文并读取或污染其累积状态。
  2. **多跳身份丢失**：身份仅在传输层逐跳建立，委托链下游无法验证原始主体，恶意中间代理可静默收集转发凭据。
  3. **未证实能力声明**：`AgentSkill` 数据模型完全由自声明字段组成，无验证或证明机制，恶意代理可虚假宣传能力来获取机密数据并返回伪造产物。
- 结论：**A2A 规范将关键安全属性（上下文所有权、委托溯源、能力证明、凭据作用域）作为实现层而非协议级不变量处理，产生了在完全合规部署中直接可利用的设计漏洞。**
- 另一个重要结论：**零样本 LLM 分析无法可靠发现这些漏洞，显式形式化基础是协议安全分析的必要条件。**

## 7. 优点

- **创新框架**：首次将 LLM 辅助形式化建模与对抗验证结合，用于协议级安全分析，具有可复现性和较低成本（40.97 美元/次）。
- **双通道语义分离**：结构提取与行为提取独立，有效降低自然语言规范中的语义混淆。

## 8. 不足与局限

- **仅规范级分析**：不涵盖具体实现、传输层安全或真实部署场景，无法穷尽所有可能漏洞。

- **零样本对比有限**：仅使用 Claude Opus 4.6 单一模型，未比较其他 LLM 或自动化协议验证工具。

- **缺少大规模仿真验证**：作者也指出目前没有专门用于模拟多智能体 A2A 部署的框架，限制了在受控条件下评估漏洞影响的能力。
