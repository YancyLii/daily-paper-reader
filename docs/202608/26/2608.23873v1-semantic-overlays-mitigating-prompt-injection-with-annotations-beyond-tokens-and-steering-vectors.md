## 摘要
语言模型所见的一切都是token。服务栈知道每个片段是什么——用户输入、工具输出、指令——但模型必须自行跟踪这些信息，而它可能丢失跟踪或被混淆：文本可以被写成看起来像任何东西。提示注入是对这一现象的一种自然利用。通过扰乱模型对片段身份的理解，攻击者可以诱导出有害甚至危险的行动。向模型输入添加非文本通道——一种在文本之外传达片段身份的方式——可以缓解这类攻击。因此，我们引入了一种通用的引导技术，称为语义覆盖层（Semantic Overlays）：在选定预填充位置应用于冻结模型残差流的、小型可学习适配器。在片段上放置覆盖层会创建一个带外标注通道，这是token无法复制的。与转向向量不同，语义覆盖层经过训练、具有适应性并可以选择性应用。覆盖层可以编码复杂语义，重塑模型对标记片段的感知：当要求复制一段代码片段，而覆盖层断言该片段使用的编程语言与实际不同时，模型会忠实地用所断言的语言重写该片段。覆盖层还可组合使用，允许透明读取底层内容，并能携带复杂负载——包括模型将遵循的命令。将某个片段标记为“不可执行”的覆盖层，可以防御在不可信上下文中添加指令的广泛提示注入类别。我们在提示注入基准上报告了强有力的结果：SEP分离度从24.3%提升到96.5%，且效用保持不变（采用我们的评分规则；我们还修正了已发布评分器中的一个缺陷）；TensorTrust攻击成功率从34.8%降至6.6%；PIArena全部四个攻击家族的合规率均降至0%；同时被标记片段保持可读（精确复制率为92.5%）。

## Abstract
Everything a language model sees is tokens. The serving stack knows what each span is -- user input, tool output, instructions -- but the model must keep track of that itself, and it can lose track or be confused: text can be written to read like anything. Prompt injection is a natural exploit of this phenomenon. By scrambling the model's understanding of span identity, an attacker can induce unwanted and potentially dangerous actions. Adding a non-textual channel to the model's input -- a way to communicate span identity beyond text -- mitigates this class of attack. We thus introduce a general steering technique called Semantic Overlays: small learned adapters applied at chosen prefill positions to a frozen model's residual stream. Laying an overlay over a span creates an out-of-band annotation channel that cannot be replicated by tokens. Unlike steering vectors, Semantic Overlays are trained, adaptable, and selectively applied. An overlay can encode complex semantics that reshape how the model perceives the marked span: asked to copy a code snippet under an overlay asserting that it is in a different programming language than it is, the model rewrites the snippet, faithfully, in the asserted language. Overlays are also composable, allow for transparent reading of underlying content, and can carry complex payloads -- including imperatives that the model will follow. An overlay which marks a span as "non-executable" defends against the broad class of prompt injections that add instructions in untrusted context. We report strong results on prompt injection benchmarks: SEP separation rises from 24.3% to 96.5% with utility unchanged (our scoring rule; we also correct a defect in the published grader), TensorTrust attack success rate falls from 34.8% to 6.6%, and all four PIArena attack families drop to 0% compliance, all while marked spans stay readable (92.5% exact copy rate).

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：语言模型看到的输入是单一 token 流；服务栈知道每个片段（span）的来源与角色（用户输入、检索文档、工具输出、指令），但模型只能从 token 文本本身推断这些信息。文本可被伪造、仿冒成任何身份，模型容易混淆、丢失对片段权限级别的跟踪。
- **提示注入的本质**：攻击者通过混淆片段身份，让模型把不可信文本当作指令执行。特殊 token 和文本分隔符可以被伪造或忽略，不能可靠解决问题。
- **现有激活引导的局限**：Activation steering（如 ActAdd、CAA、ITI、RepE、SAE clamping）通常从对比对/探针/SAE 提取一个方向，全局、统一应用；强度 α 需手工调参，效果有限（每个方向只对应一个概念，不指向具体位置）。
- **本文意图**：引入 Semantic Overlays——在冻结模型残差流上、对选定预填充位置应用的小型可学习适配器——创建非文本、带外注释通道。该通道无法被 token 复制，可标记片段身份，实现对提示注入的鲁棒防御（类似 LLM 的 NX 位：标记“不可执行”片段）。

## 2. 论文提出的方法论

### 2.1 核心思想

- **Semantic Overlay**：一个 overlay 集合包含每个解码器层一个小适配器；在标记位置（mark position）的预填充阶段，把适配器产生的 residual delta 加到隐藏状态上。模型在解码时通过 KV cache 看到被编辑的激活，从而改变对标记片段的感知。
- **定位**：标记是 per-token、per-overlay 的布尔位置掩码；只作用于预填充阶段，解码阶段不额外干预。基座模型参数完全冻结。
- **可组合性**：不同 overlay 若重叠同一 span，它们的 delta 从同一 pre-edit 状态计算并求和，组合顺序无关。

### 2.2 关键技术细节与公式

- **适配器结构**（SwiGLU 瓶颈）：
  \[
  h \leftarrow h + W_{out} \left( \text{SiLU}(W_g [n(h); c_q]) \odot W_{in} [n(h); c_q] \right)
  \]
  - \(n(h)=h/\text{rms}(h)\) 是非学习 RMS 归一化。
  - \(c_q\) 是 overlay 身份码；单一 overlay 无码时输入仅 \(n(h)\)。
  - 瓶颈宽度 32–128（论文主要实验使用 128）。
- **多 overlay 复用架构**（§4 比较四种）：
  1. Learned per-layer steering vectors（每个层每个 overlay 一个向量）。
  2. Per-overlay MLP（无码，每个 overlay 单独适配器栈）。
  3. Code-conditioned shared MLP（码 \(c_q\) 是每个 overlay 的自由 128 维向量）。
  4. Embedding-conditioned shared MLP（码 \(c_q\) 冻结为 base model 对描述短语的嵌入，如 “highlighted in red”）。
- **训练**：
  - 合成数据：对每个 overlay 构建目标 completion；可程序化构造（如全大写、标记读出）或由更强模型生成/编辑冻结模型的输出（如语言重写、拒绝、注入抵抗）。
  - 损失：交叉熵（CE）朝向目标 completion，同时训练 no-op completion（例如未标记 span 时保持不变）。三向对比显示 CE 优于 KL/CE 混合、KL alone：93.5% vs 88.5% vs 79.6% SEP separation。
  - 优化器：Muon，学习率 5e-4，输入/门控矩阵 6 倍乘子，warmup 20 步，batch size 32，2 epochs。

### 2.3 “不可执行” overlay 的构建

- 训练 corpus 基于 SQuAD passages + TriviaQA payloads，将注入帧插入 passage 的不同位置；注入项与 benign 项共享同一目标（冻结模型在干净 passage 上的 greedy completion）。
- 还包含 verbatim-copy 家族（训练可读性）、gate 家族、validator 家族。
- 应用时由服务栈对所有检索/第三方内容标记该 overlay，剥离指令权威但保留内容可读。
