## 摘要
大语言模型智能体正越来越多地以自主循环的方式部署。从单个人类目标出发，这类系统会在许多无人值守的迭代中反复发现问题、制定计划、执行工具调用、验证结果并持久化状态。然而，广泛使用的智能体安全防护机制是针对单条轨迹定义的，其安全状态会在下一条轨迹开始时被重新初始化。我们表明这是一种组合性失效，而非实现细节。我们的核心结果是一个分离结论：面对证据分散在多个迭代中的攻击，任何仅以轨迹为范围的监控器，无论其表达能力多强，其真阳性率都等于假阳性率，因为它所需的证据永远不会出现在它所观察的窗口内；而保留跨迭代状态的监控器则能将两者完美区分。我们进一步表明，携带几何衰减风险分数这一显而易见的修补方案并不充分，因为有耐心的攻击者需要等待的冷却期是一个不随时间范围 N 增长的常数。随后我们提出 LoopHarness，它在循环层面恢复持久的、非衰减的安全状态。在中介提交和仲裁器检测下限 δ_M 下，它将未经授权的不可逆动作的期望数量限制为 B+m-1+m/δ_M，该值与 N 无关，其中 B+m-1 项由无模型规则决定，因此即使验证器完全合谋也能保持有效。我们给出了完整的评估协议，包括在原生 Agent-SafetyBench 任务上配对的干净与受攻击回合、决定性证据仅跨迭代存在的外层状态攻击套件、逐模块消融实验以及自适应白盒红队测试。

## Abstract
Large language model agents are increasingly deployed as autonomous loops. Starting from one human goal, such a system repeatedly discovers work, plans, executes tool calls, verifies outcomes and persists state across many unattended iterations. The agent safeguards in wide use, however, are defined over a single trajectory, and their safety state is re-initialized when the next trajectory begins. We show that this is a failure of composition rather than an implementation detail. Our central result is a separation: against an attack whose evidence is fragmented across several iterations, every trajectory-scoped monitor has a true-positive rate equal to its false-positive rate, however expressive it is, because the evidence it would need never appears in the window it sees, whereas a monitor retaining cross-iteration state separates the two perfectly. We further show that the obvious repair of carrying a geometrically decaying risk score is insufficient, because the cooling-off period a patient adversary must wait is a constant that does not grow with the horizon $N$. We then present LoopHarness, which restores a persistent, non-decaying safety state at the loop level. Under mediated commits and an arbiter detection floor $δ_M$, it bounds the expected number of unauthorized irreversible actions by $B+m-1+m/δ_M$, a constant in $N$, of which the $B+m-1$ term is decided by a model-free rule and therefore survives a fully colluding verifier. We give a complete evaluation protocol on native Agent-SafetyBench tasks with paired clean and attacked episodes, an outer-state attack suite whose decisive evidence exists only across iterations, per-module ablations, and an adaptive white-box red team.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 在循环层面维护**持久化、非衰减的安全状态**，使跨迭代证据能够累积，而不是在每条轨迹开始时被重置。
- 将动作影响（impact）、有根据的攻击证据（grounded attack evidence）和验证器不确定性（verifier indecision）**分开处理**，只有攻击证据才贡献到持久风险值中，避免正常高风险操作或模型不确定性污染后续迭代。

### 关键技术细节
- **LoopHarness** 包含五个持久化组件，在固定阶段顺序下运行：
  - **IPM（Intake and Provenance Monitor）**：唯一入口，对新工作项执行默认拒绝的范围检查、溯源检查、重入检查、授权原子性检查等，并输出连续的入口先验分数供风险累积使用。
  - **XRC（Cross-iteration Risk Cumulant）**：维护保留风险值 Ξ，更新规则为：
    \[
    Ξ_i = \max(r_i, \gamma_i Ξ_{i-1}), \quad \gamma_i = 
    \begin{cases}
    1 & \text{若到第 } i \text{ 次迭代已有结构性标志触发} \\
    \gamma_\downarrow \in (0,1) & \text{否则}
    \end{cases}
    \]
    只有当“循环结构性标志”（如作用域扩展、拒绝工作重新进入、内存篡改等）触发时，折扣才会被锁定为 1，即风险不再衰减。几何衰减模式或完全关闭累积（XRC-off）都无法阻止有耐心的攻击者。
  - **MIG（Memory-Integrity Guard）**：使用哈希链和 HMAC 对持久化日志进行完整性保护，执行单调信任写门、再水合时审计，仅向上下文重新提供受信任条目的有界后缀，阻止降级内容重新进入上下文。
  - **ASA（Adversarially Robust Stopping Arbiter）**：分层仲裁器，包含确定性门（无模型调用）、去相关检查器（最多每迭代一次模型调用，高级层使用与写入者不同的模型），以及窗口化分歧统计量，任一检测都会停止循环。
  - **CRG（Compounding-risk Governor）**：将 Ξ 映射到能力上限和停止规则，持有风险计费提交的硬预算 B 和高级验证预算 B_adv，执行任务契约、完成限制和强制停止/升级。
- 循环级别状态 \(\sigma_i = (\Xi_i, c_i, a_i, \ell_i, M_i, R_i, K_i)\) 在迭代之间**永不重置**，其中 Ξ、提交计数器和降级级别绑定到认证检查点，防止内存妥协静默重置。

### 核心理论结果
- **命题 2（碎片化分离）**：对于任意 s≥2 和任意 s-碎片化攻击，任何轨迹范围监控器的真阳性率等于假阳性率，无论其表达能力多强；而读取跨迭代状态的监控器可以实现真阳性率 1、假阳性率 0。
- **命题 3（冷却期打败几何衰减）**：固定折扣 γ 下，证据强度 ρ 到达后，门控在常数 k* = ⌊log(ρ/θ)/log(1/γ)⌋+1 次迭代后重新开启，与 N 无关；如果证据触发结构性标志且采用非衰减更新，则门控永远不会因被动等待而重新开启。
- **定理 5（与时间范围无关的未授权提交界）**：在假设 A1（中介有界提交）、A2（仲裁器检测下限 δ_M）、A3（单调提交计数器）下，对于任意 N 和自适应攻击者：
  \[
  U^{\text{vis}}_{1:N} \le B + m - 1 \quad \text{确定性地成立}
  \]
  \[
  E[U^{\text{inv}}_{1:N}] \le \frac{m}{\delta_M}
  \]
  因此总期望未授权不可逆动作数 \(E[U_{1:N}] \le B + m - 1 + m/\delta_M\)，与 N 无关。
- **命题 6（无模型组件与其残差类）**：授权代理完全由规则对记录轨迹字段评估，不依赖模型输出，因此确定项在验证器完全合谋时仍然成立；残差类（合同不可见提交）位于操作者声明策略与实际意图之间的差距。

## 6. 论文的主要结论与发现

- **安全不具备组合性**：逐轨迹重置导致跨迭代碎片化攻击不可检测，任何单轨迹监控器的 TPR=FPR，无法以任何容量分离攻击与良性流量。
- **几何衰减不足以修复**：冷却期长度是常数，攻击者支付一次后即可无限次重新打开风险门控；非衰减闩锁才能阻止仅通过等待重新开放。
- **LoopHarness 提供与 N 无关的保证**：在假设下，未授权不可逆动作的期望数量被限制为 \(B+m-1+m/\delta_M\)，其中确定项不需要模型调用，且对完全合谋的验证器依然成立。
- **实验佐证**：
  - 在 Track B 外层攻击上，完整 LoopHarness 将总体 ASR 降至 0.1%，而基线 B0-B3 为 88.4–97.6%，同时保持 CleanGC 96.9%。
  - 逐模块消融将对应攻击家族 ASR 恢复到 96.0–97.5%，表明各组件分别负责不同威胁。
  - Track A 中 B4 在 N=5/10/20 下 cASR 均为 0%，而 B1 和 B1.5 从 2.9% 增至 6.2%。
  - XRC-latch 在 A14 冷却测试中保持 ASR 0%，而 XRC-off 和 XRC-decay 在足够长的冷却后 ASR 达 95.5–97.5%。
  - 自适应红队最终 ASR 为 0%，但最小缓解率在 A-collude 下降至 0.392，说明验证器独立性仍重要。
- 结论：循环级非衰减安全状态是修复轨迹级监控组合性缺陷的关键，而非仅仅增加单轨迹内的防御强度。

- **组件职责清晰**：五个组件各司其职，消融实验证明每个组件对应特定攻击家族，非冗余堆砌。
- **协议严谨**：预注册、配对干净/攻击回合、评估标签排除、固定排列、内容哈希种子、温度零缓存、OOD 与 dev 分离，增强了可复现性和客观性。
- **风险评估分层**：将动作影响、攻击证据和验证器不确定性分开，避免正常高风险工作导致后续风险累积，降低误报和可用性损失。
- **攻击面覆盖广泛**：Track A 覆盖轨迹内证据，Track B 覆盖仅跨迭代可判定的攻击，包括内存篡改、授权重入、结果冲突和冷却期利用。
- **明确的适用边界**：论文承认其界是期望界而非绝对缺失界，并指出检测下限是唯一经验输入，同时说明可用性条件（闩锁后可能阻碍正常任务完成），不夸大方法能力。

## 8. 不足与局限：包括实验覆盖、偏差风险、应用限制等

- **实验未做多种子/多模型复制**：每个报告矩阵仅一个种子、一套模型角色，统计稳定性和模型选择偏差风险未充分排除。
- **Track B 未严格使用 OOD split**：论文明确说明该矩阵是“控制器合同评估而非泛化估计”，因此对未见任务的泛化能力证据有限。
- **检测下限假设 δ_M 未被直接估计**：红队测试由于条件在“已尝试攻击”而非“合同不可见未授权提交”上，不能直接估计均匀检测下限，只能探测。
- **可用性权衡**：在闩锁攻击下，所有 B4 回合的 FullGC 为 0%，表明一旦结构性标志触发，系统倾向于过度停止，可能牺牲后续正常任务完成能力。
- **理论界为期望值而非缺席保证**：尽管常数界有意义，但不排除尾部风险；且常数中的 m 和 B 由操作者设置，δ_M 是环境相关的经验量。
- **发现流简化**：任务队列是调度好的而非竞争性的，低估了真实部署中 IPM 面临的准入问题；攻击者能力假设有限（无法伪造 MAC、修改内层代码）。
- **资源未报告**：未给出 API 调用总量、费用或等效 GPU 小时，难以评估实际成本。
- **范围有限**：主要针对单智能体循环，多智能体系统中“重置实体”是委托子智能体的情况被列为未来工作。
