## 摘要
使用工具的 LLM 智能体将安全风险从生成文本扩展到影响外部系统的动作。在多轮分解攻击下，有害目标可分散在各自看似合理的请求和工具调用中，仅在累积轨迹上才显现。现有防御要么依赖辅助在线推理来恢复长程安全证据，要么在生成后评估动作，通常会带来额外推理成本或依赖于运行时特定的动作表示。我们提出重组分散风险（ReDiR），一种在生成时进行防御的方法，以轨迹级安全证据为条件生成动作。在每次动作之前，ReDiR 将当前轨迹压缩为紧凑的潜在安全表示，并将其注入冻结的基础模型。该表示通过同模型、跨视图监督学习，其中来自显式任务视图的安全行为为从原始多轮轨迹中恢复分散的安全证据提供监督。这一设计使 ReDiR 能够直接在生成过程中整合跨轮次安全信息，而无需依赖单独的动作级安全模块。我们在两个智能体安全基准上，跨三个模型系列和八个留出工具域评估 ReDiR。ReDiR 将攻击成功率降低至 8% 以下，可迁移到未见工具域，并以较低的计算开销保持良性保真度。

## Abstract
Tool-using LLM agents extend security risks beyond generated text to actions that affect external systems. Under multi-turn decomposition attacks, a harmful objective can be distributed across individually plausible requests and tool calls, becoming apparent only from the accumulated trajectory. Existing defenses either rely on auxiliary online reasoning to recover long-horizon security evidence or assess actions after generation, often incurring additional inference cost or depending on runtime-specific action representations.   We propose \emph{Reassembling Distributed Risk} (ReDiR), a generation-time defense that conditions action generation on trajectory-level security evidence. Before each action, ReDiR compresses the current trajectory into a compact latent safety representation and injects it into the frozen base model. The representation is learned through same-model, cross-view supervision, where safe behavior from an explicit task view provides supervision for recovering distributed safety evidence from the original multi-turn trajectory. This design enables ReDiR to integrate cross-turn security information directly within the generation process without relying on a separate action-level safety module. We evaluate ReDiR on two agent-safety benchmarks across three model families and eight held-out tool domains. ReDiR reduces attack success rates to below 8\%, transfers to unseen tool domains, and preserves benign fidelity with low computational overhead.

- **研究背景**：LLM 智能体已从“纯文本回答”扩展到“可执行动作”。多轮交互成为主流范式，攻击者可将有害目标（如破坏性命令）拆分成多个看似合理的子步骤，分散到不同轮次中，使得单步检查无法识别风险。
- **核心问题**：多轮智能体安全是一个**轨迹级、动作接地**的问题——下一个动作必须基于整个交互历史中积累的证据来控制，而非只检查当前轮次或生成后的动作文本。
- **现有防御的局限**：
  - 运行时守卫（runtime guards）在动作生成后检查，依赖特定运行时的工具 schema 和动作格式，迁移成本高，且增加了在线安全判断开销。
  - 轨迹级防御（如 MAGE）依赖影子记忆和在线评判器，需要额外推理或策略训练，计算成本高。
  - 训练时防御（如 ToolShield）在新工具出现时需要重新进行工具特定的安全经验构建。
- **整体含义**：论文提出应把轨迹级安全证据**直接整合进动作生成过程**，在动作产生前就影响模型行为，而不是把安全决策与动作生成分离。

### 2. 论文提出的方法论
- **核心思想**：在每次动作生成前，将当前多轮轨迹压缩成一个紧凑的潜在安全表示（latent safety representation），注入到冻结的基础模型中，让分散的风险证据直接引导下一步动作。
- **三个关键阶段**：
  1. **离线动作监督构建（Offline Action Supervision Construction）**：
     - 将有害任务分解为多轮伪良性请求，执行 rollout 得到轨迹前缀。
     - 构建“折叠视图”（collapsed view），使有害目标对同一基础模型显式呈现，采样出安全的拒绝型终止动作作为监督目标。
     - 审计候选动作（安全、可执行、能终止进一步执行），并按学生模型输出与安全目标的差异进行三级路由：`NONE`（无需修正）、`TERMINATE`（只需修正终止动作格式）、`FULL`（需要全量修正）。
  2. **轨迹条件化安全训练（Trajectory-Conditioned Safety Training）**：
     - 使用与基础模型同骨干的 safety encoder，只训练轻量 LoRA 参数和 K 个可学习 latent queries。
     - 轨迹嵌入与 latent queries 拼接，经编码器得到固定大小的 `HQi ∈ R^{K×d}`，再经归一化（使 latent 范数与 token embedding 范数匹配）得 `Zi`。
     - 将 `Zi` 注入冻结基础模型：`p_{θ,φ}(y_i|c_i) = f_θ([X_i; Z_i])`。
     - 损失函数：`L_safe` 加权 token 级交叉熵，权重重点给目标推理前缀的前 E 个 token（entry weight）和 FINISH 等动作决策 token（decision weight）；另有良性行为保留项 `L_ret`（KL 散度正则化），总目标为 `min_φ L_safe + λ_B L_ret`。
  3. **潜在引导的动作生成（Latent-Guided Action Generation）**：
     - 部署时，每个动作步都用 LoRA 适配器启用 safety encoder 对当前轨迹编码，得到潜在表示后关闭适配器，由冻结骨干生成动作。
     - 只增加一次安全编码前向传播，不产生额外可见 token，不修改交互历史。

### 3. 实验设计
- **数据集 / 场景**：
  - **MT-AgentRisk**：将单轮有害工具使用任务转化为多轮攻击轨迹。包含 Addition 和 Decomposition 两种变换格式，覆盖 Data Files 与 Environment States 两类风险载体。共 365 个任务，跨 9 个工具域（Filesystem、Terminal、PostgreSQL、Notion、GitLab、OwnCloud、Reddit、Shopping、Shopping Admin）。
  - **AgentDojo**：研究通过不受信工具观察进行的间接提示注入，作为分布外威胁模型测试。
- **监督设置**：仅使用 MT-AgentRisk 中 55 个 Filesystem 任务进行训练，其余 15 个 Filesystem 任务为域内评估，其余 8 个域（295 个任务）全部留出用于跨工具迁移评估。
- **对比方法**：
  - Base（无防御）
  - ToolShield（免训练自探索防御）
  - MAGE（轨迹感知影子记忆 + 在线评判，辅助模型为 Qwen3.5-4B）
- **基础模型**：Qwen3.5-9B、Ministral-3-8B-Instruct、Gemma-4-E4B。
- **评估指标**：
  - **ASR**（攻击成功率）：有害目标是否最终实现。
  - **SSR**（安全停止率）：是否在有害目标实现前发出 FINISH 终止动作。
  - **FPR**（良性误拒率）：良性任务中是否出现不必要的拒绝。

### 6. 主要结论与发现
- **有效性**：
  - 在 MT-AgentRisk 上，ReDiR 将 ASR 降至 0.0%–7.9%，显著优于 MAGE（20.3%–34.2%）和 ToolShield（31.5%–54.7%）。
  - 在所有模型家族、变换格式和风险载体子类上均保持最低 ASR。
  - 在 AgentDojo 上，ASR 为 11.8%–13.1%（Qwen3.5-9B 和 Ministral-3-8B），Gemma-4-E4B 上为 3.5%。
- **跨工具迁移**：
  - 仅用 Filesystem 域训练，在 8 个留出域上 ASR 降至 0.0%–6.8%，SSR 为 85.8%–98.3%，说明 ReDiR 的安全表示不以工具 schema 或动作格式为基础。
- **良性保真度**：
  - 在所有评估良性任务上 FPR 为 0.0%，与 Base 和 ToolShield 持平，优于 MAGE。
- **效率**：
  - 额外 GPU 内存仅 1.328–3.250 MiB，远低于 MAGE 的 8 GB+。
  - 端到端延迟在有害任务上平均降低 53.3%（因安全终止使任务提前结束），每动作延迟增加幅度温和。
- **消融发现**：
  - 骨干不匹配会显著降低潜在引导效果，增大 K 只能部分缓解。
  - 同模型教师优于更大或外部教师，表明“目标兼容性”比“教师能力”更重要。
- **自适应攻击**：良性历史稀释攻击未导致系统性安全退化，ASR 保持在 6.7%–10.0%。

### 7. 优点
- **设计思路上有原创性**：将轨迹级安全证据直接注入生成过程，不依赖单独的 action-level safety module，这在思路上与现有 post-generation 防御形成明确差异。
- **生成时防御**：安全决策在动作生成前就影响模型输出，避免了 generate-then-check 的运行时 schema 依赖。
- **跨工具迁移性强**：在多个异构工具域上，仅用单一域监督就能实现有效迁移，说明潜在表示不局限于特定工具格式。
- **计算效率高**：在线额外内存极小、端到端延迟反而下降，训练成本也比 MAGE 低 37%。
- **同模型跨视图监督**的设计保证了安全监督目标与基础模型的自然生成行为一致，是方法有效性的关键。
- **丰富的实验与消融**：覆盖多个模型家族、多个工具域、超参数敏感性、编码器/教师兼容性以及自适应攻击场景，证据较为扎实。

### 8. 不足与局限
- **AgentDojo 上的表现非最优**：MAGE 在 AgentDojo 上 ASR 更低，ReDiR 更多是“平衡 safety 与 utility”的第二选择，在间接提示注入场景下优势不如在 MT-AgentRisk 上明显。
- **训练数据构建依赖强监督**：需要从 canonical task specification 构建“折叠视图”，并由外部 LLM（GPT-4.1-mini）进行语义审计，审计流程的可扩展性与主观性有待进一步验证。
- **良性样本规模较小**：FPR 评估仅覆盖约 50 个良性任务，难以充分证明保真度在更广泛良性场景下的稳定性。
- **威胁模型受限**：未充分考虑非白色攻击（如模型特洛伊化）、间接提示注入与分解攻击的混合场景，也未测试针对安全编码器本身的攻击（如针对 latent 表示的对抗扰动）。
- **训练数据源单一**：监督仅来自 Filesystem 域，虽然展示了强迁移性，但缺乏在更多源域上训练对性能影响的系统分析。
- **超参数调优未完全自动化**：entry-weight、decision-weight、latent query 数量等需手工设定，虽然做了敏感性分析，但缺少自动搜索或跨模型泛化的指导原则。
- **自适应攻击测试有限**：只测试了良性历史稀释这一种攻击，对抗性更强的 attacker（例如尝试污染轨迹、引入工具调用诱导）未被覆盖。
