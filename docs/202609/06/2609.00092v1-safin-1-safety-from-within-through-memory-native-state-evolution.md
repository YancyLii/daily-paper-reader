## 摘要
长周期复杂任务要求基础模型能够积累信息、维持内部状态，并在长期交互中不断适应。安全应当是模型自身的内禀属性，而不应仅仅依赖外部防护或监督微调等事后对齐的行为约束。这促使我们提出“由内而外的安全”（Safety from Within），即通过模型的原生计算来表示和调用安全相关能力。我们提出 Safin-1，这是一系列通过记忆路由和状态演化实现该原则的基础模型。Safin-1 构建于跨上下文历史的记忆锚定路由（Memory-Anchor Routing across Context History, MARCH）之上，该网络架构维护结构化记忆状态，并通过内容条件路由选择性地检索相关历史信息。它支持在测试时对持久能力状态进行自适应，而无需反复修改骨干网络，从而能在共享基础模型上实现受控的专门化。我们通过安全状态（Safety State）在下游安全任务中研究这一接口，展示了基于状态的有效自适应，并带来了显著的安全提升。更广泛地说，路由状态接口在模型的原生计算中统一了上下文记忆与持久能力自适应，将记忆从对先前上下文的被动记录重新定义为维持和演化模型行为的主动基础。在通用能力、长上下文理解、检索和效率等方面的评估进一步验证了 Safin-1。这些发现为将安全作为一种状态原生且可自适应维持的能力提供了路径。本研究仅是对“由内而外的安全”的初步架构探索，要实现这一更宏大的愿景仍需大量后续工作。

## Abstract
Long-horizon complex tasks require foundation models to accumulate information, maintain internal states, and adapt over extended interactions. Safety should be an intrinsic property of the model itself, rather than a behavioral constraint relying solely on external safeguards or post-hoc alignment such as supervised fine-tuning. This motivates Safety from Within, where safety-relevant capabilities are represented and invoked through the model's native computation. We present Safin-1, a family of foundation models realizing this principle through memory routing and state evolution. Safin-1 is built on Memory-Anchor Routing across Context History (MARCH), a network architecture that maintains structured memory states and selectively retrieves relevant historical information through content-conditioned routing. It supports test-time adaptation of persistent capability states without repeatedly modifying the backbone, enabling controlled specialization over a shared foundation. We investigate this interface on downstream safety tasks through a Safety State, demonstrating effective state-based adaptation with substantial safety improvements. More broadly, the routed-state interface unifies contextual memory and persistent capability adaptation within the model's native computation, reframing memory from a passive record of prior context into an active substrate for maintaining and evolving model behavior. Evaluations across general capabilities, long-context understanding, retrieval, and efficiency further validate Safin-1. These findings provide a path toward safety as a state-native and adaptively maintainable capability. This work is only an initial architectural exploration of Safety from Within, and substantial further work is needed to realize this broader vision.

## 2. 论文提出的方法论

Safin-1 的核心架构是 **MARCH（Memory-Anchor Routing across Context History，跨上下文历史的记忆锚定路由）**，它通过内容条件路由维护结构化记忆状态并选择性检索历史信息。主要组件包括：

- **上下文衍生状态锚点（Context-Derived State Anchors）**  
  - 在文本序列中按固定间隔（如每 512 tokens）插入共享学习锚点嵌入。锚点位置不修改循环状态，而是读取对齐的循环状态快照（checkpoint）来构造路由元数据。
  - 每个状态承载层在边界处快照累积循环状态，形成状态锚点 \(A(m,\ell)\)，保留循环状态的时间轨迹。
  - 锚点表示经投影生成路由键 \(\kappa_m\)，使路由依赖于状态内容而非仅时间索引。

- **内容路由状态检索（Content-Routed State Retrieval）**  
  - 对每个文本 token，将隐藏状态投影为路由查询 \(\rho_t\)，与所有因果可见锚点的键进行点积评分。
  - 引入一个可学习的 **空选项（null option）**，其载荷为零，允许模型在不需要历史记忆时绕过检索。
  - 通过 softmax 得到路由概率 \(\pi_{t,j}\)，对候选状态读出进行加权求和，并与当前循环状态读出相加，不改变底层循环更新。

- **持久能力状态（Persistent Capability States）**  
  - 路由状态库中除动态锚点外，还可加入可学习的矩阵值持久状态 \(P_j\)。它们从第一个 token 起即可用，不占用输入序列位置。
  - 持久状态与动态锚点共用同一路由查询和 softmax，贡献随 token 和上下文动态变化，而非固定权重。
  - 在 Safin-1 中实例化为 **Safety State**：冻结语言模型骨干，只优化各层持久安全状态，实现测试时状态级专业化。

- **高效生产者–读者实现**  
  - 循环生产者复用底层 Gated DeltaNet 的 chunkwise 高效内核。
  - 状态读者采用类似 FlashAttention 的 I/O 感知设计，联合分块查询和候选状态，避免物化稠密路由矩阵和大规模读出张量。
  - 支持 Top-K 稀疏路由（默认 Top-4），显著降低长序列下的计算和内存开销。

## 6. 论文的主要结论与发现

- **MARCH 架构有效性**  
  - 在 0.8B 受控实验中，MARCH 在 GDN、KDA、GDN2 上一致提升语言建模、LongBench、真实世界上下文检索和 RULER NIAH，尤其在多针任务和长度外推（32K/64K）上优势明显。
  - 消融显示内容路由、null 选项、合适的锚点间隔（512）和 Top-K 稀疏路由对性能和效率平衡至关重要。

- **Safin-1 大规模收益**  
  - 4B 和 35B-A3B 上，Safin-1 在十个能力基准中分别提升 7 个和 9 个，AIME 2025 提升 8 分以上，MMLU-Pro、GPQA-Diamond 等难题收益显著，同时 GSM8K/MATH 等稳定。
  - 平均越狱 ASR 在 4B 和 35B-A3B 分别降低 0.60 和 1.00 个百分点，安全鲁棒性提升，过度拒绝变化有限。

- **Safety State 的安全–效用权衡**  
  - 4B：平均 ASR 从 6.65 降至 3.84（降幅 42.3%），优于 LoRA 的 5.33；XSTest ORR 仅增 0.40，远低于 LoRA 的 5.00；四个能力基准全部优于 LoRA。
  - 35B-A3B：平均 ASR 从 5.89 降至 2.81（降幅 52.3%），优于 LoRA 的 3.04；XSTest ORR 增 2.00，低于 LoRA 的 10.00；但能力保留任务依赖（MATH/AIME 优于 LoRA，MMLU-Pro/MBPP 不如 LoRA）。

- **总体结论**  
  Safin-1 展示了循环状态可作为可寻址的长时程记忆基板，并通过同一路由接口承载持久安全状态，实现不修改骨干的测试时专业化。这为 Safety from Within 提供了初步的、可扩展的架构证据。

## 7. 优点

- **架构创新**：将循环状态轨迹转化为可寻址的状态锚点库，分离了状态更新与历史访问，既保留原生循环路径又增加可寻址性。
- **状态原生安全**：Safety State 作为持久矩阵值状态，通过原生路由路径被调用，与上下文记忆统一，无需修改骨干权重，支持模块化附加/移除。
- **控制实验严谨**：小规模实验匹配训练设置并跨多个循环骨干验证；大规模实验在同一初始化下对比；Safety State 与 LoRA 训练匹配，对比公平。
- **效率设计**：Top-K 稀疏路由将状态读取成本从稠密降低约一个数量级，在 128K 长度下吞吐量超过稠密 MARCH 甚至 FlashAttention-2，兼顾了长上下文效率。
