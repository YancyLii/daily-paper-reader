## 摘要
现代大语言模型（LLM）智能体常常通过聚合来自多个外部来源的检索段落、用户评论和文档来构建提示。这种范式使其暴露于片段级投毒攻击：攻击者只需控制一小部分来源，即可注入恶意内容以操纵模型输出。现有防御主要依赖文本模式、外部嵌入或辅助检测器，因此可能难以应对流畅且语义上合理的毒化片段；同时它们在定位问题片段方面也能力有限。我们观察到，成功的污染证据攻击和对抗指令攻击会在 LLM 的内部激活中引起结构性偏移，形成一种一致的激活空间模式，我们称之为毒化方向。基于这一观察，我们提出了 ActProbe，一个基于内部状态的框架，用于在多源 LLM 输入中检测和定位毒化片段。ActProbe 将 MLP 激活投影到学习到的毒化方向上，并使用在小型校准集上训练的轻量线性 SVM 来检测受污染的提示。随后，它应用 BinRoL，该方法结合了递归替换消融、基于马氏距离的分支剪枝以及基于 MAD 的稳健叶节点检测，以定位毒化片段。ActProbe 无需修改后端 LLM，并将定位开销从 O(n) 的穷举探测降低到 O(k log n) 次前向传播。在三个数据集、两种攻击和四个开放权重 LLM 上，ActProbe 实现了 0.01 的假阳性率、0.05 的假阴性率、0.94 的定位召回率和 0.90 的定位 F1 分数。它对防御感知的自适应攻击仍然有效，并可通过基于替代模型的毒化片段删除来保护黑盒 API。

## Abstract
Modern large language model (LLM) agents often construct prompts by aggregating retrieved passages, user reviews, and documents from multiple external sources. This paradigm exposes them to segment-level poisoning attacks, in which an adversary controlling only a small subset of sources injects malicious content to manipulate model outputs. Existing defenses mainly rely on textual patterns, external embeddings, or auxiliary detectors and may therefore fail against fluent, semantically plausible poisoned segments. They also provide limited support for locating the responsible segments. We observe that successful corrupted-evidence and adversarial-instruction attacks induce structured shifts in the LLM's internal activations, forming a consistent activation-space pattern that we call the poison direction. Based on this observation, we propose ActProbe, an internal-state-based framework for detecting and localizing poisoned segments in multi-source LLM inputs. ActProbe projects MLP activations onto a learned poison direction and uses a lightweight linear SVM trained on a small calibration set to detect contaminated prompts. It then applies BinRoL, which combines recursive replacement ablation, Mahalanobis-distance-based branch pruning, and MAD-based robust leaf detection to locate poisoned segments. ActProbe requires no modification to the backend LLM and reduces localization overhead from O(n) exhaustive probing to O(k log n) forward passes. Across three datasets, two attacks, and four open-weight LLMs, ActProbe achieves a 0.01 false-positive rate, a 0.05 false-negative rate, 0.94 localization recall, and a 0.90 localization F1-score. It remains effective against defense-aware adaptive attacks and can protect black-box APIs through surrogate-based poisoned-segment removal.

## 1. 核心问题与研究背景

- **研究动机**：现代 LLM 智能体（如 RAG 问答、评论摘要、新闻聚合）普遍将来自多个独立外部来源的文本片段（segment）拼接为提示，这种设计在安全上存在关键弱点——攻击者只需控制少量来源，即可注入恶意片段，诱导模型生成攻击者指定的输出。
- **威胁类型**：论文聚焦两类代表性攻击：(1) **知识投毒**（如 PoisonedRAG），注入语义流畅但事实错误的证据；(2) **提示注入**（如 ObliInjection），在外部片段中嵌入对抗性指令，且对片段顺序变化具有鲁棒性。
- **现有防御的局限**：基于困惑度、外部嵌入或辅助检测器的方法容易漏检"流畅且语义上合理"的毒化片段；大多数方法仅做二分类检测，较少支持问题片段的定位；定位方法（如 PromptLocate）主要针对显式注入模式，对纯数据投毒效果欠佳。
- **核心观察**：无论知识投毒还是提示注入，成功的攻击都会在 LLM 内部 MLP 激活中引起沿特定几何方向的结构性偏移，该方向在样本之间保持一致，论文称之为 **毒化方向（poison direction）**。这为检测和定位提供了比表面文本特征更直接的信号。

## 2. 方法论：ActProbe 框架

ActProbe 由**离线校准**和**在线推理**两个阶段构成，核心组件包括：

### 2.1 毒化方向探针（Poison Direction Probe）

- 对每个校准提示，提取**最后 token** 在各层的 MLP 激活 \(h_l \in \mathbb{R}^d\)（如 Llama-3.1-8B 中 \(d = 14336\)，\(L = 32\)）。
- 计算第 \(l\) 层的毒化方向为毒化激活与干净激活的归一化均值差：
  \[
  v_l = \frac{1}{M}\sum_{i=1}^{M}\left(h^p_{i,l} - h^c_{i,l}\right),\quad v_p[l] = \frac{v_l}{\|v_l\|}
  \]
- 将任意激活投影到该单位向量上，得到标量 \(s_l = h_l \cdot v_p[l]\)，整段提示被压缩为 \(s \in \mathbb{R}^L\) 的低维特征。
- 论文强调该方向优于 PCA（抓主方差而非攻击信号）和随机投影，能保留对抗扰动印记并过滤任务无关的语义噪声。

### 2.2 投毒提示检测（Poison Prompt Detection）

- 在标准化后的 \(L\) 维投影特征上训练 **线性 SVM**，决策规则为 \(\hat y = \mathrm{sign}(w^\top \tilde s + b)\)。
- 利用 SVM 权重的绝对值 \(|w_l|\) 筛选最具判别力的层，供定位阶段使用。
- 同时用干净校准样本估计良态激活分布参数 \((\mu, \Sigma^{-1})\)，加入 Tikhonov 正则化 \(\lambda = 10^{-6}\) 保证可逆性，这些参数在定位阶段直接复用。

### 2.3 投毒片段定位：BinRoL 算法

一旦检测为投毒提示，启用 BinRoL 定位问题片段，核心机制包括：

- **替换消融**：将候选片段替换为中性文本（如"No relevant information is available for this query."），保持片段槽位和上下文结构不变，抑制待测片段的语义与对抗内容。实验证明替换消融优于物理删除消融。
- **下降比（Drop Ratio）**：计算替换前后投影特征到良态分布的**马氏距离**，下降比定义为
  \[
  \rho = \frac{d(s_{\text{full}}) - d(s_{\text{rep}})}{d(s_{\text{full}})}
  \]
  较大的 \(\rho\) 表示该片段对恶意信号贡献较强。
- **递归二分窄化（Binary Narrow）**：将候选集合二分为左右半区，分别替换并计算 \(\rho\)，若任一侧超过阈值 \(\delta\) 则进入该分支探索，直至集合不超过叶大小 \(\ell\)。
- **稳健叶节点检测（Robust Leaf）**：对父节点 \(P(C)\) 内每个片段计算细粒度消融得分
  \[
  a_i = \frac{1}{|L_{\text{top}}|}\sum_{l\in L_{\text{top}}} \left(h^{full}_l - h^{rep}_{i,l}\right) \cdot v_p[l]
  \]
  然后基于父节点集合的 **MAD（中位数绝对偏差）** 统计量设置异常阈值：\(a_i > \tilde m + \gamma \cdot \hat \sigma\) 视为投毒片段。
- **复杂度**：递归深度约 \(\lceil \log_2(n/\ell) \rceil\)，每次分支出两次前向，当 \(k\) 个投毒片段激活 \(k\) 条路径时，总定位开销为 \(O(k(\log(n/\ell) + \ell))\)，即 \(O(k \log n)\)。

### 2.4 黑盒 API 防护

- 对闭源模型（如 GPT、Gemini），ActProbe 用开放权重 LLM 作为**上游诊断替代模型**，检测并移除投毒片段后再将净化后的提示发给目标 API，无需访问目标模型内部状态。

## 6. 主要结论与发现

1. **检测性能显著优于基线**：ActProbe 平均 FPR 0.01、FNR 0.05，而最佳基线 DataSentinel 为 FPR 0.08、FNR 0.61；ROC-AUC 在 0.95–1.00 之间。
2. **定位能力强**：平均 Recall 0.94、F1-score 0.90，明显优于最强基线 FRA（F1-score 0.43）。
3. **对自适应攻击保持有效**：在面对改写、信号稀释、密度递增和防御感知攻击时，性能虽有所下降但仍显著优于基线。
4. **跨攻击/跨数据集迁移具有不对称性**：从 PoisonedRAG 到 ObliInjection 的迁移优于反向迁移；QA 数据向 Amazon Reviews 迁移优于反向迁移。
5. **每个组件都有实质贡献**：线性 SVM 在低维投影空间足够有效；毒化方向投影优于 PCA 和随机投影；替换消融优于删除消融；MAD 稳健叶检测优于 z-score。
6. **校准样本量在 100 时趋于饱和**，验证了少样本校准的可行性。
7. **黑盒保护有效**：通过上游替代模型净化提示，平均将 ASR 从 0.29 降至 0.02，同时将 ACC 从 0.71 提升至 0.87。

## 7. 优点

- **视角新颖**：从外部文本表征转向 LLM 内部激活空间，用可解释的毒化方向捕捉攻击印记，对流畅、语义合理的投毒内容具有更强鉴别力。
- **检测与定位一体化**：ActProbe 同时解决两个耦合问题，且定位阶段直接复用检测阶段估计的分布参数，避免额外校准开销。
- **高效的定位策略**：BinRoL 将复杂度降至 \(O(k\log n)\)，在实际设置（n=50、k=5）中比逐片段检测快 2.43 倍，兼顾准确性与效率。
- **无需修改后端 LLM**：通过"诊断-净化"的管道式设计保护黑盒 API，实用性较强。
- **消融实验系统而严谨**：对分类器、降维方法、消融策略、叶检测统计量、校准集大小等关键设计逐一验证，支撑充分。
- **对防御感知攻击的评估**：论文主动考虑了攻击者了解防御参数的情景，增强了结论的说服力。

## 8. 不足与局限

- **高密度投毒的定位性能下降**：当 \(k=5\)（n=10）时 Recall 降至 0.62，表明 MAD 的"少数异常"假设被削弱，定位准确性与鲁棒性在此场景受限。论文虽承认此问题，但未提出有效改进。
- **跨攻击目标迁移有限**：从工具劫持到答案操纵的跨目标 FNR 高达 1.00，说明毒化方向高度依赖攻击目标的激活模式，单一探测器难以覆盖异构攻击场景。
- **依赖校准集的攻击代表性**：论文明确承认 ActProbe 的性能取决于校准集对部署时攻击家族与数据域的覆盖，对分布外攻击（激活模式显著不同）可能失效。
- **超长上下文的局限**：论文指出长上下文可能扩散毒化信号，last-token 探针效果减弱，相关工作尚待探索。
- **跨架构适配需要重新校准**：不同 LLM 的隐藏维度不同，毒化方向无法直接迁移，每个模型需要独立校准（虽然 50 样本即可有效）。
- **黑盒 API 评估的可信度存疑**：实验使用的闭源模型名称（如 GPT-5.4-mini）在现实中不存在，可能并非真实 API 测试；若为模拟环境，则其"黑盒保护"结论的实际通用性有待独立验证。
- **效率分析的范围有限**：表 16 的效率对比仅在 Amazon Reviews（n=50）一个设置下进行，未给出在不同 \(n\)、\(k\) 下的详细开销分析。
- **自适应攻击仍会造成性能下降**：表 14 中 HotpotQA 上 PoisonedRAG 自适应攻击将 FNR 从 0.02 推高至 0.21（Llama）和 0.25（Mistral），定位 Recall 也有明显下降，表明该方法面对充分了解防御机制的攻击者仍有可能被进一步绕过。
