## 摘要
大语言模型（LLMs）仍然容易受到越狱攻击，这些攻击利用角色扮演、混淆、代码转换和多步间接引导等技术来诱使模型输出有害内容。随着越狱策略不断涌现，防御手段在持续的猫鼠游戏中大量增加，但大多数防御仍然是静态的：其安全行为在部署时即被固定，因此无法积累防御经验或适应未见过的策略。我们提出一种自进化的测试时防御，其核心是一个持久的、跨交互的规则记忆：当攻击成功时，框架将这一失败抽象为一条方法级规则，捕获结构性攻击包装而非有害主题，并将其复用于未来输入。由于规则是方法级的，一条归纳出的规则可以泛化到整个攻击家族，并且随着新型包装的出现，标签空间会不断扩展。该机制完全通过外部记忆和提示来运行，无需更新参数，并且适用于开放权重模型和黑盒API模型。我们将其实现为四个协同工作的模块，但核心贡献在于基于记忆的自适应机制，而非模块划分。在四个黑盒越狱攻击家族和多个模型上，我们的方法大幅降低了攻击成功率，同时保持良性效用，在自适应复合包装攻击下仍保持鲁棒性，并且随着记忆增长不会增加过度拒答。

## Abstract
Large language models (LLMs) remain vulnerable to jailbreak attacks that exploit techniques such as role-playing, obfuscation, code transformation, and multi-step indirection to elicit harmful outputs. As jailbreak strategies keep emerging, defenses have proliferated in an ongoing cat-and-mouse game, yet most remain static: their safety behavior is fixed at deployment, so they cannot accumulate defensive experience or adapt to unseen strategies. We propose a self-evolving test-time defense built around a persistent, cross-interaction rule memory: when an attack succeeds, the framework abstracts that failure into a method-level rule capturing the structural attack wrapper rather than the harmful topic, and reuses it against future inputs. Because rules are method-level, one induced rule generalizes across an entire attack family, and the label space expands as novel wrappers appear. The mechanism operates entirely through external memory and prompting, with no parameter updates, and applies to both open-weight and black-box API models. We realize it as four cooperating modules, but the contribution is the memory-based adaptation mechanism, not the module decomposition. Across four black-box jailbreak families and multiple models, our method substantially reduces attack success rates while preserving benign utility, remains robust under an adaptive composite-wrapper attack, and does not increase over-refusal as the memory grows.

- 多智能体安全防御（如 AutoDefense、AegisLLM）虽然引入多模块协作，但每次交互独立处理，不保留跨交互的防御知识。

## 2. 论文提出的方法论

### 2.1 核心思想

- 维护一个**外部持久规则记忆** \(R_t\)，初始为空 \(R_1=\emptyset\)。
- 当一次攻击成功（模型输出有害内容）时，反思模块将该失败抽象为一条**方法级规则**，捕获的是攻击的结构性包装（如嵌套角色扮演、代码混淆）而非具体有害主题。
- 规则形式为：`[label=Li] If the request uses Pi, then Di`，其中 \(L_i\) 是方法级攻击标签，\(P_i\) 描述结构性攻击包装，\(D_i\) 规定拒绝约束。
- 因为规则是方法级的，一条规则可泛化到同一攻击家族的多个实例；同时，遇到结构全新包装时，标签空间自动扩展。

### 2.2 关键操作符与流程

- 定义五个操作符：
  - **攻击模式分类器** \(\phi\)：将输入 \(x^{(t)}\) 映射到一个方法级标签 \(z^{(t)}\)；若检测不到越狱包装则返回 `benign`；若与已有标签匹配则复用；否则返回 `other`，后续若引发不安全输出则归纳新规则和新标签。
  - **规则检索与触发** `match`：根据 \(z^{(t)}\) 从记忆中选择最多 \(K=2\) 条相关规则。匹配采用三阶段谓词：标签优先匹配；若无，则用 LLM 相关性评分回退；再若无，则用词法关键词重叠启发式。
  - **策略操作符** \(g\)：将触发的规则子集映射到三种响应策略之一：`hard-refuse`（高风险，严格拒绝并禁止操作细节）、`soft-refuse`（中等风险）、`allow`（默认，无规则触发时）。冲突时优先级为 hard-refuse > soft-refuse > allow。
  - **违规检测器** \(h\)：LLM-as-judge，对生成响应 \(y^{(t)}\) 按 1–10 危害性打分，阈值 \(\tau=7\)，\(v^{(t)}=1\) 表示攻击成功。该检测器使用与智能体相同的模型，而评估用外部 GPT-4o-mini，避免优化偏差。
  - **规则归纳 \(F\) 与记忆更新 \(U\)**：当 \(v^{(t)}=1\) 且 \(z^{(t)}\neq \text{benign}\) 时，归纳新规则 \(r_{\text{new}}=F(x^{(t)}, y^{(t)})\)；更新时进行语义去重，并对每个标签设定容量上限 \(C=4\)。

### 2.3 算法流程（Algorithm 1）

- 对每个输入 \(x^{(t)}\)：
  1. \(z^{(t)} \leftarrow \phi(x^{(t)})\)（分类攻击包装）
  2. \(R_t(x^{(t)}) \leftarrow \{ r_i \in R_t \mid \text{match}(z^{(t)}, r_i) \}\)（检索最多 \(K\) 条规则）
  3. \(\pi(x^{(t)}) \leftarrow g(R_t(x^{(t)}))\)（决定策略）
  4. \(y^{(t)} \leftarrow f_\theta(x^{(t)}; \pi(x^{(t)}))\)（生成响应，将策略动态注入系统指令）
  5. \(v^{(t)} \leftarrow h(x^{(t)}, y^{(t)})\)（判断是否违规）
  6. 若 \(v^{(t)}=1\) 且 \(z^{(t)}\neq \text{benign}\)，则 \(r_{\text{new}}\leftarrow F(x^{(t)},y^{(t)})\)，\(R_{t+1}\leftarrow U(R_t,r_{\text{new}})\)；否则 \(R_{t+1}\leftarrow R_t\)。
- 良性输入和不安全响应不会触发规则归纳，记忆只在真实失败时增长。

### 2.4 四智能体实现

- A1 规则触发智能体：实现 \(\phi\) 和 `match`。
- A2 策略决策智能体：实现 \(g\)，输出 `ALLOW`、`HARD_REFUSE` 或 `SOFT_REFUSE`。
- A3 响应生成智能体：根据策略动态组合系统指令（硬拒绝模式下注入严格的安全合同）。
- A4 反思智能体：运行 \(h\)，检测违规后执行 \(F\) 和 \(U\)。
- 作者强调：贡献在于基于记忆的自适应机制，而非特定的模块分解。

## 6. 论文的主要结论与发现

- 提出的自进化记忆防御机制在四种黑盒越狱攻击家族和多个模型上大幅降低攻击成功率（ASR-gpt 普遍降至接近 0，尤其在 DeepInception、CodeChameleon、ReNeLLM、FlipAttack 上表现优于所有基线）。
- 与静态提示和实例级反思相比，方法级规则加选择性触发能更有效地泛化到同一攻击家族的新实例，并在交互流中快速收敛。
- 良性任务效用（MMLU/GSM8K）保持在与无防御模型相差约 2 个百分点以内，表明鲁棒性提升不以牺牲可用性为代价。
- 自我进化分析显示：规则记忆从空开始，第一批样本学习后，后续轮次 ASR 迅速降至近零，验证了方法级规则的跨样本泛化能力。
- 在自适应复合包装攻击下仍保持鲁棒，且记忆增长不会显著增加过度拒答（XSTest 从空记忆的 3.6% 增至积累记忆后的 9.6%，主要因分类器误判，而非记忆效应本身）。

## 7. 优点

- **方法级规则泛化**：从单个失败中归纳的规则可覆盖整个攻击家族，极大提高了防御效率。
- **无需参数更新**：完全通过外部记忆和提示操作，适用于开放权重和黑盒 API 模型，部署灵活。
- **动态触发机制**：只激活与当前输入相关的规则，避免将所有规则简单拼接带来的上下文干扰和过度拒答。
- **真实冷启动评估**：记忆从空开始，在线流式评估，无数据泄漏，结果更接近实际部署。
- **学习信号与评估信号分离**：违规检测用内部模型，评估用外部 GPT-4o-mini，避免对评分器的优化偏差。
- **可解释性强**：规则以自然语言形式存储，便于审计和调试。
- **实验设计扎实**：包含多模型、多攻击、多基线、消融、敏感性分析和过度拒答分析，验证了机制的有效性和组件必要性。

## 9. 总体评价

- 论文针对LLM防御中静态安全机制与持续演化攻击之间的根本性不匹配，提出了基于外部持久规则记忆的自进化测试时防御框架，动机清晰、定位准确。
- 方法通过方法级规则抽象、动态触发和反思归纳，在不更新模型参数的前提下实现跨交互知识积累，兼顾防御效果与良性任务性能，具有很强的实用性和部署灵活性。
- 实验采用冷启动在线协议、内部学习信号与外部评估信号分离，并在多个开源与闭源模型、多种攻击家族上验证，结果可信度高；消融与敏感性分析进一步确认了各组件的必要性。
- 主要不足在于依赖LLM组件的判断质量、冷启动脆弱性、推理开销以及长期记忆管理的可扩展性，但这些也为未来工作提供了明确方向。
- 总体而言，该工作为自进化、可解释、轻量级的测试时安全防御提供了一个有价值的范式，尤其适合无法直接微调模型的黑盒API场景，具有较高的研究参考价值和实际应用前景。
