## 摘要
工具增强的大型语言模型（LLM）智能体通过工具调用作用于外部系统，能够自动执行复杂的多步任务，如网页导航、代码生成和工作流编排。然而，LLM 中的幻觉、分布不稳定性与对抗性操控，以及某些工具调用的不可逆后果，可能导致有害结果。现有防护措施要么用随机 LLM 评判器事后对记录的轨迹评分，要么一次一个调用地阻断不安全动作，且没有单一确定性构件能同时支持这两种角色。我们提出了 ContrAgent，一个基于契约的框架，用于对 LLM 智能体进行符号时序监督。ContrAgent 将智能体的行为捕获为工具调用序列，并将其形式化为固定可检查谓词集上的迹。随后，它使用有限迹线性时序逻辑（LTLf）中的假设-保证契约来规定所需行为。每个契约被编译为确定性有限自动机（DFA），该自动机承担两种角色：在线门控智能体动作，以及离线评估记录的轨迹。契约库作为可复用知识库，独立于智能体模型维护，并可应用于同一任务领域中的不同智能体。我们在涵盖两种角色的四个基准上展示了方法的有效性，ContrAgent 与最先进的 LLM 评判器和基于规则的护栏基线表现相当，同时产生确定性、可复现的判定；在线模式下，每次调用的延迟低几个数量级。

## Abstract
Large language model (LLM) agents augmented by tools can automate complex, multi-step tasks, such as web navigation, code generation, and workflow orchestration, by acting on external systems through tool calls. However, hallucinations, distributional instability, and adversarial manipulations in LLMs, and the irreversible consequences of certain tool calls can lead to harmful outcomes. Existing safeguards either grade recorded trajectories post hoc with stochastic LLM judges or block unsafe actions one call at a time, and no single deterministic artifact supports both roles. We present ContrAgent, a contract-based framework for symbolic temporal supervision of LLM agents. ContrAgent captures an agent's behavior as a sequence of tool calls and formalizes it as a trace over a fixed set of checkable predicates. It then specifies required behaviors using assume-guarantee contracts in linear temporal logic over finite traces (LTLf). Each contract is compiled to a deterministic finite automaton (DFA) that serves two roles: gating agent actions online and evaluating recorded traces offline. A contract library, acting as a reusable knowledge base, is maintained independently of the agent's model and can be applied across different agents within the same task domain. We show the effectiveness of our approach on four benchmarks spanning both roles, where ContrAgent matches state-of-the-art LLM-judge and rule-based guardrail baselines while producing deterministic, reproducible verdicts and, in the online mode, orders-of-magnitude lower per-call latency.

## 2. 方法论

### 2.1 核心思想

- 将智能体行为抽象为**工具调用迹（trace）**，即工具调用与返回事件的有序序列。
- 使用一组**可检查的交互谓词（interaction predicates）**作为原子命题，将轨迹形式化为符号序列。
- 用**假设-保证契约（Assume-Guarantee, A/G）**描述智能体应满足的时序需求，逻辑语言为**有限迹线性时序逻辑（LTLf）及其算术扩展 ALTLf**。
- 每个契约编译为**确定性有限自动机（DFA）**，DFA 同时承担在线强制（gating）和离线评估（grading）两种角色。

### 2.2 关键技术细节

- **Agent Session 定义**：一个会话状态 `s = (τ, κ, ρ)` 包含：
  - `τ`：到目前为止的事件迹；
  - `κ`：从事件中记录的上下文键值对；
  - `ρ`：数值计数器（如工具调用次数、token 消耗量）。
- **交互谓词**（表 1）分为两类：
  - **结构谓词**：如 `Call(T)`（调用工具 T）、`ArgHas(T,f,p)`（参数匹配）、`OutHas(T,p)`（返回值匹配）、`Flow(s,d)`（数据流）、`Perm(P)`（权限）等。
  - **数值谓词**：如 `Cnt(T)`（调用计数）、`Num(T,f)`（参数数值）、`Tok`（累计 token），通过算术比较（`≤, <, ≥, >, =`）构成 ALTLf 原子。
- **A/G 契约语义**（Definition 2）：对轨迹 τ，契约取三值之一：
  - `1`（IDLE）：环境未满足假设；
  - `e`（ACTIVE）：假设与保证都满足；
  - `0`（FAIL）：假设满足但保证被违反。
  - 顺序为 `0 ≤ e ≤ 1`。
- **契约编译**：
  - 从自然语言需求或政策文档中，通过 LLM “先提升后锚定”（lift-then-ground）生成 ALTLf 公式，再由确定性步骤将占位符锚定到交互谓词词汇表。
  - 每个契约公式编译为 DFA，读入每个事件的谓词估值并转移状态；数值谓词在 grounding 阶段求值，不编码进 DFA。
  - 契约库独立于具体 LLM 模型，可跨智能体复用。
- **运行时监督**：
  - **在线强制（σ）**：逐事件推进所有 DFA，若某事件使任意契约 verdict 不再为 `(e,e)`，则在工具执行前 `block`（默认）或重定向/升级；假定被违反的 return/input 事件被 `suppress`，保持会话在安全前缀。
  - **离线评估（μ）**：重放记录轨迹，返回 end-of-trace verdict `v(τ)`，确定性、可复现。
  - 检查是增量的：保留残余公式逐步推进，每个事件成本为 `O(|C|)`，与轨迹长度无关；离线大量轨迹时 DFA 构建一次，每事件为 `O(1)` 表查找。

## 3. 实验设计

- **AgentDojo（间接提示注入预防）**：

- **R-Judge（智能体安全风险离线评估）**：
  - 571 条多轮智能体记录，覆盖 10 类操作风险（301 unsafe / 270 safe）。

  - 指标：F1、precision、recall。
- **τ2-bench（程序违规与结果评分）**：
  - 3 个领域（零售、航空、电信），多模型（Claude 3.7、GPT-4.1、GPT-4.1-mini、o4-mini）。
