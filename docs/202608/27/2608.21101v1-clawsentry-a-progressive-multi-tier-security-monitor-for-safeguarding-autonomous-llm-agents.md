## 摘要
随着大语言模型（LLM）智能体从对话转向执行代码、读取本地文件以及编排外部工具，单个智能体一旦被恶意第三方技能劫持，就可能导致数据外泄、权限提升或级联式失陷。我们认为智能体风险是渐进式的：它可能在智能体控制循环的四个环节进入——技能准入、调用时意图、执行时效果和动作后后果——而被拒绝的危险目标可能以不同表面形式、工具或轮次再次出现；现有防护通常只局限于某一个生命周期边界或某一次调用。在该威胁模型指导下，我们提出了 ClawSentry，一个面向智能体运行时的开源、框架无关的安全监督网关。在技能包被执行之前，首次使用技能包审查（FSPR）会在确定性证据下限下对其进行审计，并将未决案例升级到受限的只读智能体审查（环节 A）。在运行时，一个由确定性 L1 层、规则锚定的 L2 语义审查器以及只读的 L3 证据搜寻智能体组成的三层渐进式决策引擎，仅将上下文审查用于剩余歧义；同时，会话级防绕过机制能够识别工具切换和改写重试（环节 B–C）；动作后路径将高严重性证据非追溯地输入到后续审查中（环节 D）。智能体挂载协议（AHP）抽象可在 Codex、Claude Code、Kimi CLI 和 Gemini CLI 之间应用同一策略，而无需修改智能体内部。在 SkillInject 与 Codex/GPT-5.4 的测试中，上下文 ASR 从 39.55% 下降到 2.61%，而上下文 TSR 仅从 83.78% 变为 83.05%。在完整 SkillsSafety 基准上的五个工作智能体中，ClawSentry 将 ASR 从未防护时的 33.5%–49.7% 限制到 9.09%–15.03%，而干净技能上的总体 TSR 保持为 98.7%。

## Abstract
As large language model (LLM) agents move from conversation to executing code, reading local files, and orchestrating external tools, a single agent hijacked by a malicious third-party skill can cause data exfiltration, privilege escalation, or cascading compromise. We argue that agentic risk is progressive: it can enter at four loci of the agent control loop--skill admission, invocation-time intent, execution-time effect, and post-action consequence--while a denied dangerous objective can reappear across surface forms, tools, or turns; existing safeguards are typically local to one lifecycle boundary or one call. Guided by this threat model, we present ClawSentry, an open-source, framework-agnostic security supervision gateway for agent runtimes. Before a skill package is ever executed, First-use Skill Package Review (FSPR) audits it under a deterministic evidence floor, escalating unresolved cases to bounded read-only agentic review (locus A). At runtime, a three-tier progressive decision engine--a deterministic L1 layer, a rule-anchored L2 semantic reviewer, and a read-only L3 evidence-seeking agent--spends contextual review only on the residual ambiguity, while a session-level anti-bypass mechanism recognizes tool-switching and rephrased retries (loci B--C); a post-action path feeds high-severity evidence non-retroactively into later review (locus D). An Agent Harness Protocol (AHP) abstraction applies one policy across Codex, Claude Code, Kimi CLI, and Gemini CLI without modifying agent internals. On SkillInject with Codex/GPT-5.4, contextual ASR falls from 39.55% to 2.61% while contextual TSR moves only from 83.78% to 83.05%. Across five Work Agents on the full SkillsSafety benchmark, ClawSentry confines ASR to 9.09--15.03% from 33.5--49.7% unprotected, and aggregate TSR on clean skills remains 98.7%.

- **整体含义**：提出并实现 ClawSentry——一个框架无关、覆盖技能准入、运行时决策和动作后反馈的渐进式安全监督网关，目标是在保持良性任务成功率几乎不变的前提下，大幅降低攻击成功率。

## 2. 论文提出的方法论

- **总体架构**：ClawSentry 通过 Agent Harness Protocol（AHP）将 Codex、Claude Code、Kimi CLI、Gemini CLI 等异构智能体事件流统一为 CanonicalEvent；安全核心只处理规范事件，新增框架只需编写适配器。
- **四风险点覆盖**：
  - **环节 A（技能准入）**：首次使用技能包审查（FSPR），在包执行前进行只读、包级证据审计，结合确定性规则地板和受限智能体审查，缓存决策。
  - **环节 B–C（调用意图与执行效果）**：运行时三层渐进式决策引擎：
    - **L1 确定性策略引擎**：无模型调用，通过效应归一化、危险工具/目标/命令短路、会话风险滑动窗口等方式直接关闭明确案例。
    - **L2 规则锚定语义分析器**：基于版本化 YAML 攻击模式（默认 25 条，覆盖 OWASP ASI01–ASI05）加单轮 LLM，可提升但不可轻易降低 L1 风险。
    - **L3 只读证据智能体**：多轮、只读工具包（无执行、写入、网络权限），仅审查残余歧义，其技能清单与全局只读白名单求交。
  - **环节 D（动作后后果）**：异步审计工具输出中的间接指令、秘密暴露、外泄等；已完成事件不追溯，但高危证据可提升后续动作审查等级。
- **效应归一化与风险快照**：将不同表面形式（shell、脚本、原生工具调用）映射为统一效应包（capability、target、scope、artifact role、evidence provenance），使用六维风险维度（D1 工具危险、D2 目标敏感、D3 命令危险、D4 会话累积、D5 智能体信任、D6 注入信号），并按公式 \(B_t = w_{123}\max(D1,D2,D3) + w_4 D4 + w_5 D5\)，\(S_t = B_t(1+\lambda D6/3)\) 计算综合风险，用于路由而非最终判定。
- **防绕过机制**：会话级记忆被拒绝效应（capability+target 指纹），在普通分层选择之前查询；精确重复和归一化危险效应确定性处理，不确定跨工具等价则升级至 L3，分离“语义识别”与“语义权威”。
- **会话信任与最小权限**：可选会话范围配置记录任务实际所需权限，仅通过操作员通道授予，作用单调（只能收紧不能放宽）。
- **评审器定位**：外部监督者，受三约束——有限暴露（选择性升级漏斗）、无执行权（只读工具包）、可扩展先验（版本化 YAML 规则与评审技能）；监督不绑定单一模型家族。

## 6. 论文的主要结论与发现

- **安全性大幅提升**：
  - SkillInject Codex/GPT-5.4：上下文 ASR 从 39.55% 降至 2.61%，上下文 TSR 仅下降 0.73 个百分点。
  - SkillsSafety 五个工作智能体：ASR 从原始 33.5–49.7% 收缩至 9.09–15.03%，绝对降幅 21.1–39.5 个百分点。
- **良性任务保持**：干净技能任务成功率总体 98.7%，原始为 100%，说明保护并非通过拒绝普通工作实现。
- **任务成功边际分解**：干净技能 TSR 50.0%，有毒技能（无防护）31.7%，说明投毒自身已破坏 18.3 点；ClawSentry 硬阻断再降 6.7 点（至 25.0%），约四分之三成本发生在任何网关决策之前，其余为强制边界代价。
- **FSPR 判别能力强**：minimax-m2.7 识别全部 48/48 有毒包并接受 49/53 干净包；kimi-k2.5 识别 43/48 并接受 50/53；干净误拦率 5.7–7.5%。
- **FSPR 硬阻断优于软响应**：硬阻断 ASR 8.47% vs 运行时反馈 10.53% vs 警告 24.56%；警告几乎无效，因为攻击者已塑造上下文。
- **组件贡献显著**：移除 FSPR 使 ASR 增加 11.00 点；移除防绕过使 ASR 增加 6.57 点。
- **对比 claude-guardrails**：ClawSentry 将 ASR 降低 48.52 点（8.62% vs 57.14%），规则钩子几乎未改善（原始 58.33%）。
- **评审器可替换**：五家评审器保护 ASR 在 11.11–17.24%，远低于未防护范围，证明安全边界来自网关而非单一模型。
- **渐进漏斗高效**：83.6% 的 L1 事件无模型调用即关闭；模型支持请求仅占 L1 的 13.8%，L3 仅占 1.37%。
- **核心结构主张**：准入时审查（FSPR）优于运行时干预，因为一旦毒包进入上下文，其良性价值已被破坏，运行时只能限制损害；真正安全与效用的双重保障应在任务开始前（准入、分发渠道）实现。

## 7. 优点

- **框架无关设计**：AHP 将安全策略与具体智能体框架解耦，新增框架仅需适配器，实验覆盖四种主流 CLI。
- **生命周期全覆盖**：同时处理技能准入、调用意图、执行效果、动作后后果，并识别跨形式、跨工具、跨轮次的绕过。
- **渐进式审查与成本控制**：L1 确定性短路处理大多数事件，昂贵语义审查仅用于残余歧义，避免全量 LLM 审查，并降低评审器暴露面。
- **安全约束设计严谨**：评审器只读、无网络/写入/执行权限；L3 技能清单与全局白名单求交，防止特权扩展；风险打分仅用于路由，最终裁决权归网关。
- **实验评估全面**：多工作智能体、多基准、干净与有毒混合、消融、响应模式、评审器替换、请求量分析，且采用基准自带判定器保证可信。
- **诚实报告代价**：主动量化并分解 TSR 下降中投毒自身破坏与强制过阻的占比，而非将安全收益与效用影响混为一谈。
- **开源**：代码、配置与评审规则以 MIT 协议公开。

## 8. 不足与局限

- **非自适应攻击评估**：基准攻击不针对 ClawSentry 的 L1 短路、L2 模式、指纹等设计，政策感知攻击者可能构造绕过；作者承认需要专门的适应性评估。
- **基准覆盖有限**：主要针对技能型编码智能体，未覆盖浏览器/GUI 智能体、长时多智能体协作、非英语任务等场景。
- **动作后环节仅报告不阻止**：因为主流 harness 无法追溯修改工具返回结果，事后处理只能异步审计和提供证据，不能撤回已发生效果；其可测量的阻断贡献有限。
- **任务成功代价**：受保护 TSR 下降 5.0–14.7 个百分点（技能安全基准中有毒包）；其中约 6.7 点为强制执行过度阻断，部分源于无人值守将 Defer 映射为 Block，交互式部署可部分缓解。
- **未报告实际算力与延迟**：论文只给请求量比例，没有 GPU、token 成本、端到端延迟测量，部署成本难以直接评估。
- **过度依赖准入审查**：核心结论将效用损失归因于毒包已进入上下文，因此强调准入；但准入本身误拦仍有 5.7–7.5%，且运行时若需准入后动态威胁仍需依赖分层机制。
- **依赖基准既有评判器**：SkillInject 使用 LLM 评判器可能引入内在噪声；SkillsSafety 的 ASR/TSR 受其确定性验证器设计限制。
