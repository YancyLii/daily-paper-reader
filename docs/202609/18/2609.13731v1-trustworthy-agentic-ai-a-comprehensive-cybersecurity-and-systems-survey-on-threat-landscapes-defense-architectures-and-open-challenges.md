## 摘要
从被动基础模型向自主、目标导向的智能体人工智能系统的转变，通过耦合递归认知推理循环、持久记忆架构、实时工具执行平面和多智能体协作拓扑，带来了前所未有的能力。然而，赋予概率神经核心跨文件系统、网络和云基础设施的执行权限，消解了经典安全边界：自然语言同时充当输入数据、内部控制代码和通信协议，暴露出图灵完备的爆炸半径，其中不可信数据即代表可执行指令。本综述为可信赖的智能体人工智能提供了一个综合的系统安全参考框架，综合了206项基础研究和监管标准。我们将通用智能体架构形式化为有状态五元组，并建立涵盖安全性（security）、安全（safety）、隐私、可解释性、公平性和问责性的六维可信赖性分类法。我们系统分析执行循环内部和交互平面上的威胁面，制定了多层零信任纵深防御架构，整合双大型语言模型隔离、基于能力的访问控制、内核eBPF探针和沙箱化运行时，审查了标准化评估基准，并将技术控制映射到国际人工智能治理框架。

## Abstract
The transition from passive foundation models to autonomous, goal-directed agentic AI systems has introduced unprecedented capabilities by coupling recursive cognitive reasoning loops, persistent memory architectures, live tool execution planes, and multi-agent collaboration topologies. However, granting probabilistic neural cores execution authority across filesystems, networks, and cloud infrastructure dissolves classical security perimeters: natural language simultaneously serves as input data, internal control code, and communication protocols, exposing a Turing-complete blast radius where untrusted data represents executable instructions. This survey delivers a comprehensive systems-security reference framework for trustworthy agentic AI, synthesizing 206 foundational studies and regulatory standards. We formalize the general agent architecture as a stateful 5-tuple and establish a 6-dimensional trustworthiness taxonomy covering security, safety, privacy, explainability, fairness, and accountability. We systematically analyze threat surfaces across intra-execution loops and interaction planes, formulate a multi-layered zero-trust defense-in-depth architecture integrating Dual-LLM isolation, Capability-Based Access Control, kernel eBPF probes, and sandboxed runtimes, review standardized evaluation benchmarks, and map technical controls to international AI governance frameworks.

## 2. 论文提出的方法论

### 2.1 智能体架构形式化

- 通用智能体被建模为**有状态 5 元组**：  
  \[
  A = \langle C, M, T, E, \Pi \rangle
  \]
  其中：  
  - \(C\)：认知推理核心（基础模型参数 \(\theta\)）；  
  - \(M\)：分层记忆子系统（工作记忆 \(M_{work}\)、情节记忆 \(M_{episodic}\)、语义记忆 \(M_{semantic}\)）；  
  - \(T\)：工具与动作平面，每个工具 \(t_j = \langle Schema_j, Exec_j, Perm_j \rangle\)；  
  - \(E\)：外部操作环境（文件系统、网络、云 API、人类操作者、同伴智能体）；  
  - \(\Pi\)：执行策略/编排协议。

### 2.2 部分可观测马尔可夫决策过程（POMDP）建模

- 真实系统状态 \(s_t\) 不可完全观测，智能体维护信念状态 \(b_t(s)\)。
- 信念状态通过贝叶斯更新递归演化；当恶意环境观测 \(o_{adv}\) 被注入时，会诱导信念散度：
  \[
  D_{KL}(b^{true}_t \parallel b^{adv}_t) \gg 0
  \]
  导致策略选择错误动作，而在模型内部保持高置信度。

### 2.3 6 维可信度分类法

论文将传统静态机器学习评估重构为操作级系统属性：

2. **安全与运行鲁棒性（Safety & Operational Robustness）**：有界动作包络、不可逆动作需人工授权、幻觉抑制、分布鲁棒性。
3. **隐私与数据保护（Privacy）**：零泄漏 API 调用、差分隐私噪声注入、多租户上下文隔离。

5. **公平性与非歧视（Fairness）**：跨人口统计群体的动作分配公平、多智能体拍卖防共谋。
6. **问责与溯源（Accountability & Provenance）**：W3C DID 签名、Merkle 审计树、非否认性。

## 6. 论文的主要结论与发现

- **安全边界根本性崩塌**：自然语言的“数据=控制=通信”特性使智能体系统本质上比传统软件更易受攻击，提示注入等攻击可从对话级威胁升级为主机接管、RCE 和云权限提升。
- **威胁面具有全谱系、跨平面特征**：内部推理、工具参数、外部环境、持久记忆、多智能体共识均可被利用，且攻击可组合、可自动传播（如 Morris II 蠕虫）。
- **单一防护机制不足**：提示工程和启发式过滤器很容易被绕过；必须采用系统级零信任纵深防御，将经典安全原则（最小权限、能力令牌、微虚拟机、内核监控、加密溯源、BFT）与神经-符号验证、双重 LLM 隔离相结合。
- **六维可信度存在帕累托权衡**：安全与延迟、隐私与效用、安全与自主性之间无法同时最大化；需要风险感知的动态护栏调度。
- **开放挑战决定未来方向**：实时形式化验证、终身动态对齐、可扩展拜占庭共识、机器速度攻防不对称、以及去中心化价值生态（ZK-ML）等是尚未解决的瓶颈。
