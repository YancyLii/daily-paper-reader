## 摘要
递归 LLM 智能体可以通过生成专用子智能体来扩大搜索范围。某些分支随后会请求发送数据或部署代码的工具。一个分支应在何时获得行动权限？我们区分沙箱生成（外部控制可防止指定危害）与能力激活（被选中的分支跨越不可逆行动边界）。渐进式风险授予（PRV）将轨迹级风险预算托管起来，并在分支被激活时从中扣减。我们证明了自适应生成树的任意时间危害上界。分支结果可能相互依赖，但每个局部证书都需在完整的激活前历史（包括用于选择请求的信息）条件下保持有效。当激活门控、分支收费和计算约束保持不变时，延迟授予保留了在不可撤销生成收费下所有可用策略。边际风险估计在分支选择后仍可能失效。在一个简化的分支模型中，轨迹危害随权限再生数 $\mathcal{R}_A$ 跨过 1 而变化。当局部风险 $p$ 趋于零时，轨迹危害在临界以下与 $p$ 成正比，在临界处与 $\sqrt{p}$ 成正比，在临界以上保持一个正的下限。有限类型占用模型给出了风险和计算资源的影子价格。对于单位风险边际价值递减的嵌套扇出模式，这些价格产生了一个阈值规则。分支计算与一个拆分样本实验说明了这些结果。这些合成研究不用于估计已部署智能体的安全性。该分析提示了一条设计规则：在沙箱中广泛搜索，审慎授予递归权限，并明确收取风险费用。

## Abstract
Recursive LLM agents can broaden their search by spawning specialists. Some branches later request tools that send data or deploy code. When should a branch receive authority to act? We distinguish sandbox spawning, in which external controls prevent the specified harm, from capability activation, in which a selected branch crosses an irreversible-action boundary. Progressive Risk Vesting (PRV) holds a trajectory-level risk budget in escrow and debits it as branches are activated. We prove an anytime harm bound for adaptively generated trees. Branch outcomes may be dependent, but each local certificate needs to remain valid conditional on the full pre-activation history, including the information used to select the request. When activation gates, branch charges, and compute constraints are held fixed, delayed vesting preserves every policy available under irrevocable spawn charging. Marginal risk estimates can still fail after branch selection. In a stylized branching model, trajectory harm changes as the authority reproduction number $\mathcal{R}_A$ crosses one. As local risk $p$ approaches zero, trajectory harm is proportional to $p$ below criticality, proportional to $\sqrt{p}$ at criticality, and retains a positive floor above it. A finite-type occupancy model yields risk and compute shadow prices. For nested fanout modes with decreasing marginal value per unit risk, these prices produce a threshold rule. Branching calculations and a split-sample experiment illustrate the results. These synthetic studies do not estimate safety in deployed agents. The analysis suggests a design rule: search broadly in the sandbox and grant recursive authority sparingly, with an explicit risk charge.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想：渐进式风险授予（Progressive Risk Vesting, PRV）**
  - 将轨迹级风险预算 **δ** 放入托管（escrow）。
  - 分支在沙箱中自由生成、消耗计算资源，但不消耗风险预算。
  - 仅当某个分支被批准跨越激活边界时，才从预算中扣减该分支的风险额度 \(a_i\)。

- **关键形式化设置**
  - **沙箱树 \(T_S\)** 与 **权威树**：沙箱节点可推理、读取不可变任务局部数据、创建新沙箱节点；激活表示从沙箱推理转向可导致指定灾难的行动或能力。
  - **激活序列**：批准请求按时间编号 \(i=1,2,\dots\)，被拒绝的请求不进入序列。
  - **条件证书**：对于第 \(i\) 个激活，要求
    \[
    P(H_i \mid F_{i-1}) \le a_i,
    \]
    其中 \(H_i\) 是第 \(i\) 个激活导致灾难的事件，\(F_{i-1}\) 是批准前可用的全部历史信息，包括用于选择该请求的信息。
  - **预算约束**：\(\sum_i a_i \le \delta\) 几乎必然成立。

- **定理 1（选择有效的树保证）**
  - 对于自适应生成的可数沙箱树，若每个已批准激活满足上述条件证书且总花费不超过 δ，则
    \[
    P\left(\bigcup_{i\ge 1} H_i\right) \le \delta.
    \]
  - 不要求分支独立，也不要求预先设定树深或拓扑；允许分支结果任意依赖，只要条件证书在完整预激活历史下保持有效。
  - 证明基于 Boole 不等式、塔性质与单调收敛。

- **命题 1（期权价值优势）**
  - 固定相同的沙箱、激活门、计算约束和每个分支的收费 \(b_v\)。
  - 生成时收费（spawn charging）在分支创建时不可撤销地预留 \(b_v\)，即使分支被丢弃也不回收。
  - 渐进授予则在激活时收取 \(b_v\)。
  - 因为激活分支集合是生成分支集合的子集，所以任何生成收费下可行的策略在渐进授予下同样可行；渐进授予的最优期望效用至少不低。

- **分支过程相变（定理 2）**
  - 设每个权威节点平均生成 \(m\) 个沙箱候选，每个候选以概率 \(s\) 获得权威；权威后代数 \(K\) 的生成函数为
    \[
    \psi(z) = \phi(1-s+sz), \quad R_A = E[K] = ms.
    \]
  - 每个权威节点独立以概率 \(p\) 造成局部灾难。
  - 无灾难概率 \(h(p)\) 是最大不动点，满足
    \[
    h = (1-p)\psi(h).
    \]
  - 三种渐进状态：
    - \(R_A < 1\)：\(R(p) = p/(1-R_A) + O(p^2)\)。
    - \(R_A = 1\)：\(R(p) \sim \sqrt{2p/\beta}\)，其中 \(\beta = \psi''(1)\)。
    - \(R_A > 1\)：\(\lim_{p\downarrow 0} R(p) = 1-\xi\)，\(\xi\) 为灭绝概率，即存在非零风险下限。

- **有限类型占用模型与影子价格（定理 3）**
  - 将权威节点分为有限类型 \(i\)，每种类型有可用模式 \(a\)，模式具有效用 \(w_{ia}\)、计算成本 \(c_{ia}\)、激活收费 \(r_{ia}\)，以及类型间子代期望矩阵 \(M_{ia,j}\)。
  - 在均匀次临界假设下，规划问题等价于占用测度线性规划：
    \[
    \max_{y\ge 0} \sum_{i,a} y_{ia} w_{ia}
    \]
    满足流平衡、风险预算 \(\sum y_{ia} r_{ia} \le \delta\)、计算预算 \(\sum y_{ia} c_{ia} \le \bar C\)。
  - 强对偶给出风险价格 \(\lambda\)、计算价格 \(\nu\) 与延续价值 \(V_i\)。
  - 对嵌套整数扇出模式，若单位风险边际价值递减，则最优扇出为“最大边际比率不低于 λ”的阈值规则，类似于基本库存策略。

- **PRV 治理器算法（Algorithm 1）**
  - 根节点和后代仅以沙箱能力启动。
  - 对每个激活请求按原子准入顺序处理：
    1. 不可变绑定请求详情、请求者与谱系。
    2. 确定性策略规则拒绝则拒绝或请求人类收窄。
    3. 计算选择条件证书 \(a_i\)。
    4. 若 \(a_i\) 超过未承诺的谱系托管额度，则拒绝或要求更窄修订。
    5. 否则原子扣减 \(a_i\) 并授权一次执行。
  - 扣减在暴露后保持；重试需重新通过门控。

## 6. 论文的主要结论与发现

- **轨迹级风险预算可在自适应递归树中强制执行**：只要每个激活在完整的预激活历史（包括选择信息）下满足条件证书，托管预算就能给出任意时刻灾难概率上界，即使分支相互依赖、拓扑自适应。
- **延迟授予不劣于生成收费**：固定条件下，渐进式风险授予保留了所有生成收费可行策略，并可因避免为未激活分支预留风险而提高效用。
- **统计选择风险存在**：边际风险估计或为固定流水线校准的证书，在父节点选择性升级可疑/困难分支后可能失效，因此必须基于选择所用的信息进行条件化。
- **权威再生数决定风险相变**：
  - 权威再生数 \(R_A < 1\)：轨迹危害与局部风险 \(p\) 线性。
  - \(R_A = 1\)：轨迹危害与 \(\sqrt{p}\) 同阶。
  - \(R_A > 1\)：存在正的风险下限，即使局部风险趋于零也无法消除。
- **影子价格与阈值规则**：在有限类型次临界占用模型中，风险和计算影子价格可指导局部模式选择；对单位风险边际价值递减的嵌套扇出模式，最优授权遵循阈值规则。
- **设计规则**：在沙箱中广泛搜索，审慎授予递归权限，并显式收取风险费用。

分析；对不同 \(\delta\)、成本函数形式、候选分布（如厚尾或对抗性候选）未做稳健性检验；统计选择风险也仅作理论讨论，未在数值实验中演示边际校准在选择性升级后如何失效。

## 9. 总体评价与启示

- 论文在概念和理论层面做出了有价值的贡献：将“沙箱生成”与“不可逆能力激活”分离，并提出风险托管和条件证书，为递归智能体的授权问题提供了可审计的数学框架。
- 其实用性取决于两个未解决前提：能否获得有效的条件证书，以及沙箱是否能可靠阻止目标危害。若这两个前提不成立，理论保证无法直接转化为部署安全。
- 论文更适合作为安全架构设计原则和风险预算机制的理论基础，而非现成的工程安全方案。后续研究应结合真实安全基准、学习型监控器校准、沙箱逃逸测试和共同失效模型来验证该框架。
